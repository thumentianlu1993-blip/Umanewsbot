第４０回　デイリー杯２歳Ｓ
　
　
素質馬マルカシェンク、外から鋭く伸びて１番人気に応える
　デイリー杯２歳Ｓ（ＧＩＩ）で１枠１番に入ったマルカシェンク。わずか１戦１勝の戦績ですが、その１勝は出遅れながら差して３馬身突き放した圧勝のデビュー戦。加えて父サンデーサイレンス、母はイタリア１０００ギニー勝ち馬のシェンクという血統もあいまって素質を高く評価され、単勝オッズ１.６倍という断然の人気を集めました。

　道中は馬群後方のインコースで脚をためたマルカシェンクは、３コーナーから４コーナーにかけて少しずつ外へと持ち出されます。直線入口では、先にスパート態勢へと移ったエムエスワールドに一瞬前をふさがれる形になりましたが、鞍上・福永騎手はひと呼吸置き、さらに外へと進路を取って追い出し開始。雨に濡れた芝を四肢で力強く叩いて鋭く伸び、最後は２着ダイアモンドヘッドに２馬身差をつけてゴールへと達します。
　確かに、類稀な才能を感じさせるレースぶり。２歳王者へ向けて、そして３歳クラシックロードへ向けての強烈なデモンストレーションとなった勝利でした。
