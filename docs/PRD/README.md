# PRD 归档目录

用于保存项目迭代过程中收到的 PRD。

## 归档规则

1. 每次收到新 PRD，都存档到本目录。
2. 文件命名建议：`YYYY-MM-DD_原文件名.md`。
3. 同主题多版本不覆盖旧文件，按日期继续追加。
4. 开始较大改造前，先阅读相关 PRD 和 [project_status.md](E:/Codex/docs/project_status.md)。
