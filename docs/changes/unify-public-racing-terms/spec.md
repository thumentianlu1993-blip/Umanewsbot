# spec：多语言赛马术语统一与公开内容修复

## 背景与根因

同一实体在不同语言来源中没有稳定汇聚到同一个正式术语：

- `Kalpana`、`カルパナ` 与中文 `幻梦逸想` 未形成完整别名链；
- 文章有时保留英文名、有时保留日文转写、有时使用中文名；
- 同一赛事出现“乔治六世锦标”“英王乔治锦标”等模型变体，而产品正式简称应为“英皇锦标”；
- 现有匹配受来源语言、地区元数据、别名覆盖和英文 occurrence 语境门禁影响，导致文章之间不一致。

根因不是单篇翻译失败，而是“源文 -> 正式实体 -> 中文展示”三层缺少完整、经审核的多语言映射，
且公开字段没有统一的最终术语一致性门禁。

## 已确认产品规则

1. 本赛事公开正式简称统一为“英皇锦标”。
2. 已有可靠中文名的马匹，公开标题、摘要、正文和标签必须一致使用中文名。
3. 源文和来源证据永久保留；身份或中文名不可靠时保留原文，不猜译。
4. 现有已发布文章需要受控修复，但不得重发 QQ。

## 范围

- 建立一个正式 `TermEntry` 对应一个实体/赛事概念，多语言拼写使用 `TermAlias` 汇聚。
- 修正 `Kalpana / カルパナ -> 幻梦逸想` 和英皇锦标的首批完整映射。
- 盘点同场其他参赛马和赛事别名，只有证据充分、身份唯一的映射进入正式候选。
- 在翻译、AI 改写和发布前增加公开字段术语一致性检查。
- 对已发布文章生成逐字段 dry-run 修复包，获准后只做 occurrence 级替换。
- 让赛事详情、赛果、新闻和标签复用同一正式中文展示值。

## 非目标

- 不把任何拉丁字母首字母大写词都当作马名。
- 不按字符串相似自动合并马匹或跨年度赛事。
- 不重译整篇文章，不覆盖人工编辑字段。
- 不改变源文、来源 URL、公开时间、slug、QQ delivery 或赛事赛果。
- 不在没有证据时为所有参赛马强行创建中文名。

## 数据契约

- `TermEntry` 是正式概念，`target_zh` 是唯一公开中文展示值。
- `TermAlias` 保存英语、日语等源语言写法；别名必须带 `source_language`。旧中文译名保存在
  `TermEntry.aliases_zh`，不伪造为源语言 alias。
- `racing_region` 表示实体/赛事适用范围，不得照搬新闻来源地区；跨地区参赛马允许全局或权威归属。
- 每个正式映射必须保留来源证据、审核状态和稳定 identity。
- 同语言同 surface 匹配多个 active 正式术语时 fail closed。

## 验收标准

### 首批术语

- `Kalpana` 与 `カルパナ` 唯一解析到中文 `幻梦逸想`。
- 英文全称、常用短称和日文写法唯一解析到赛事中文简称 `英皇锦标`。
- 旧的“乔治六世锦标”“英王乔治锦标”等只作为中文历史/搜索别名，不作为公开 canonical。
- 地区、语言和实体类型元数据与证据一致。

### 新文章

- 标题、摘要、正文、push summary 和标签对同一已确认实体使用同一 `target_zh`。
- 英文同形普通词只在 occurrence 级强赛马语境或结构化实体证据成立时替换。
- 日文马名别名精确命中但实体存在冲突时保留原文并阻断自动发布。
- AI 改写不能重新引入已知非 canonical 别名；发布门禁给出字段和 occurrence 证据。

### 已发布文章

- dry-run 显示 article ID、字段、原值哈希、替换 occurrence、目标术语和证据。
- 只修改未人工锁定且命中已批准唯一映射的公开中文字段与标签。
- 不改变 `body_ja_raw/body_ja_normalized/title_ja` 等源文。
- 不改变 workflow、公开时间、slug、QQ delivery、通知或重新触发发布信号。
- 重放同一批准包幂等；任一 before hash 漂移则整批停止。

### 公共展示

- 同一文章及不同来源文章中不再混用 `Kalpana / カルパナ / 幻梦逸想`。
- 本赛事新闻、赛事详情及相关列表统一显示“英皇锦标”。
- 未审核名称保持原文，不以页面模板临时翻译掩盖数据缺口。

## 失败边界

- 术语身份、地区、语言、类型或来源证据冲突：候选进入人工审核，不激活、不修复文章。
- 文本中的 occurrence 无法证明是赛马实体：保留原文。
- 已发布字段被人工编辑、before hash 漂移或映射版本变化：跳过或整批阻断，不覆盖。
- 修复包不得被视为生产写入授权；apply 需单独成功 review、冻结 SHA 和用户授权。
