JRA单独的内部浏览器服务负责网页获取；Django仍持有来源许可、配额、事件lease与写入权。浏览器不访问数据库，不暴露宿主端口；仅允许JRA公开赛事路径，单并发、临时上下文、关闭时释放。禁止复制用户登录信息或规避拒绝。无需手工打开Chrome。

真实探针确认：accessT地址栏URL没有提交参数；将真实CNAME附到GET会返回参数错误。浏览器必须从官方页面正常调用其doAction表单提交。CNAME只从真实页面链接取得，不能猜校验后缀。限制资源类型和主机；分别记录页面导航数与浏览器资源请求数、拒绝及耗时。

NAR沿官方专题→实际DebaTable→实际RaceMarkTable，HTTP有界请求。比赛名使用raceTitle h3，不能把导航h2当比赛。取消、除外与同着保留。源页面完整归档用于全字段回溯。

JRA accessT特别登录名单不含正式赛时/马号/闸位；只生成registration候选。已有完整出马表或结果时禁止低阶段回退。不存在的名单标记not_published，不填示例或旧年度内容。

本次全量验收样本为70场，日历已存在不重建。历史赛果补齐与未来刷新分开记录，不能受短期发现窗口影响漏掉九月赛事；具体生产变更与回滚在固定发布包中列明。自然正式出马表/赛后变化延期，但已有历史真实页面回放与幂等测试仍需通过。
