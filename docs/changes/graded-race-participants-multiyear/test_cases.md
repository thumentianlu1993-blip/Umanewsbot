# 测试用例

## 赛事口径

1. 数字名次全部纳入，不再限制前五名。
2. PU、DNF、F、UR、BD、DSQ 等实际出赛状态纳入。
3. SCR、NR、withdrawn、未出赛等排除。
4. 同一赛事同一马重复行应失败，而非静默去重。
5. 完赛且在范围内的赛事没有任何实际出赛行时应报错。

## 年份与范围

6. `--year` 为必填参数，且不再硬编码 2026。
7. 默认 cutoff 为目标年 12 月 31 日。
8. 指定 cutoff 必须与目标年一致。
9. 每个 output directory 的 run manifest 只绑定一个年份和 cutoff。

## 地区与等级

10. 澳大利亚、德国、阿联酋/沙特/卡塔尔/巴林标签可直接识别。
11. “其他 + Meydan”可保守识别为中东。
12. URL override 优先于页面标签和提示。
13. 日本 Jpn/J-G 分级赛事纳入；其他地区仅 G1/G2/G3。
14. 无法唯一判断的“其他”赛事不得猜测地区。

## 马名

15. 中文、日文、英文三列始终存在。
16. 英文名移除 `(IRE)` 等产地后缀。
17. 日本和中国香港允许英文名为空。
18. 其他地区英文名为空时进入 name review queue，并令英文名质量门禁失败。
19. 不存在任何 Wikipedia/Wikidata 输出字段或网络步骤。

## 续跑与分片

20. 已成功 checkpoint 的对象在 `--resume` 后不重复请求。
21. 分片归属与输入顺序无关。
22. 合并阶段缺少任一输入键时 fail closed。
23. time budget 到期时保存 progress/index，并返回安全停止码 75。
24. 临时文件不能作为正式 checkpoint 输入。

## 最终输出

25. 输出文件名包含年份。
26. summary 包含赛事数、参赛记录数、去重马匹数、地区统计、结果状态统计和缺失必备英文名数。
27. README 明确覆盖基于 UmaFans 当前公开且 data-quality-complete 页面。
