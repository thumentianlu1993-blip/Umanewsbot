## 采集与核验口径

- 历史公开元数据从 2008-01-01 到 2025-01-24 逐日核查，6234/6234 日已缓存；较新档案覆盖官网当前赛季目录，103 个目标会议均已读取。旧目录日期另做核对，对仅标 S 的会议补查卡页以判断举办国。
- 举办国逐场确定，避免同一转播组内的澳大利亚、爱尔兰等伴随赛事混入。依据为官方逐场字段、明确场地备注、官方历史赛程，或有日期的主办方赛程。美国跨夜日期保留原始日期，并在旧目录核对时允许相差一天。
- 完整中文名单要求官网返回非空名单、来源行编号独立、中英姓名逐行齐全。28 场旧卡存在接口马号重复，保留原始值并标记 `source_horse_numbers_unique=false`；不因为编号异常丢弃有效名称，不把马号单独用于身份匹配。
- 官方繁体中译名保留；仅清除末尾国家标记，同时保存 `chinese_source_raw`。不擅自统一同名、异译或转简体。
- 日本原名来自 JRA 官方日文 PDF／赛果与英文节目／赛果交叉对齐，再核对赛马会英文名与可用血统；跨日使用姓名＋父母＋出生年，或旧卡父母均缺失时使用姓名＋出生年＋完整练马师英文名。每条记录包含匹配依据及来源，不生成音译原名。
- 人物原名优先在同一已核马匹的同场角色内匹配；仅凭全局唯一拉丁形式补配的 3 条日文候选单列为身份待核，未当作确定实体。
