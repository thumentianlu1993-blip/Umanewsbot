2026-10-29 有界人工取样，免费、匿名、无需会员，不绕付费墙。本轮交付证据盘点，不修改业务解析器、调度、开关、迁移或生产数据。**已补充11个地区/子区的明确更正案例和法国最终名单；仍不能把55项能力全部标为可运行。** 人工确认边界引用根 [AGENTS.md](../../../AGENTS.md)。

## 证据层级

[matrix.json](matrix.json) 将九个大区拆为 JRA、NAR、HK、GB、IE、FR、US、AU、DE、AE、SA，共55个能力单元。`HISTORICAL_SAMPLE` 表示沿用既有样本和离线记录，本轮仅重新核对19份fixture摘要；`SOURCE_SAMPLE_ONLY` 是新来源的单场公开证据；`PARTIAL` 是证据不足；`UNKNOWN` 是没有足够证明。没有一个状态等于自动化许可、完整覆盖、时效或生产 `runtime_verified`。

[evidence.json](evidence.json) 保存16份实际读取材料的URL、获取时刻、完整响应SHA、事实和限制。原文留在所列本机持久runtime目录，不随Git交付；Git内保存人工整理事实，不复制整份公报及无关个人信息。远端页面可能变化，重新下载产生不同SHA时应另记新观测，不覆盖历史原文。失败尝试也保存在原文目录：旧德国节目册404；新节目册第一次超过12MB读取上限，随后对同一公开链接以32MB上限完整获取14,597,033字节。这不是登录或访问控制绕行。

- 法国：France Galop 的2026 Prix du Jockey Club文章明确写最终出赛名单，列16匹及抽签位置。它证明该来源这一场的成熟度，**不改变ZEturf既有样本的UNKNOWN，也未接入新的producer**。
- 德国：赛场公开节目册第44–45页列2026 Diana-Trial第5场8匹、闸位及骑手，与官方赛事1363168交叉核对。节目册是正式参赛资料，但没有独立最终申报标志和赛前获取时刻；本轮保守保持PARTIAL。2027 Diana页面的 `Ausschreibung/Nennungen` 是报名阶段负例；不能因有马名或申报截止日而升级。既有Galopp-Statistik的 `Startfeld` 仍不足以证明最终申报。
- 美国：本轮历史更正公告没有解决既有来源最终申报名单缺口，保持UNKNOWN。
