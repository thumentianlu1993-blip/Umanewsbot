# 验证范围

- 日历默认/指定年份/搜索/指定非允许地区均不返回其他地区；选项仅五地区。
- 非允许地区 canonical、legacy、registry 兼容详情均 404；五地区详情正常。
- 首页近期赛事、重点赛事、周焦点筛选在切片前执行。
- sitemap 与年份列表排除其他地区及其独占年份；缓存不复用旧键。
- 新闻列表/详情和马匹详情的关联赛事不泄露隐藏赛事。
- 马匹生涯记录与主胜鞍按关联赛事地区或独立记录地区筛选，分页数量一致；后台数据未修改。
- 五地区既有日期、年份、分页、归属及公开字段回归；新闻地区注册仍保持原范围。
- 历史盘点区分取消、空日期、重复/分场与真正缺口；具体修复另附来源、前后值、幂等和恢复验证。

自动测试仅连接本机隔离数据库、内部容器网络和内存缓存/队列，不访问生产或第三方。

- 允许地区详情中的隐藏地区分场父/子、canonical 推荐和系列冠军不会展示，隐藏冠军不占用 fallback 年份。
- 生涯记录仅 result 关联时取 result.event 地区；event/result 指向不同赛事时隐藏，两个关联皆空才回退 race_region。

## 历史修复补充

- 旧骑手包：原缓存 SHA、马号马名、原列空值、来源身份，跨行漂移整包回滚，重复 apply/restore。
- 日本字段包：只允许空字符串补值；source_refs SHA、既有完赛名次和新增非完赛前置行集合绑定；缺失原件/不符身份不生成补值。
- 新增未完赛/取消行无官方名次；真实页面对应行显示“未完赛”或“取消出走”，JRA“中止”不推断为“拉停”。
- 空表包：空表前提、草稿取消不误公开、法国完整 17 匹名单；目标同步、幂等、完整前态恢复。
- restore 拒绝后续生涯/P0 来源关联，保留新的用户数据；相关 P0 缺陷取得真实 RED 后 GREEN。
- 三个实际 manifest 全量种入隔离 PostgreSQL，dry-run/apply/apply/restore/restore；结束回滚种子事务。
