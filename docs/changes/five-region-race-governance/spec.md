# 五地区赛事治理收口

用户于 2026-11-13 要求仅保留日本、香港、法国、美国、英国的公开赛事；检查这些地区 2026 年 9 月前已有数据的缺口并尝试修复。初始明确指令覆盖范围确认；人工确认统一引用根 AGENTS.md。

## 公开范围

赛事日历及地区选项、首页赛事模块、详情 canonical/legacy 直链、站点地图、新闻/马匹的结构化赛事关联、马匹生涯赛事记录和主胜鞍只展示五地区赛事。其他地区与地区不明的赛事不再通过这些入口展示。详情直链返回 404。后台保留全部原始赛事、关联和审计，未来新增的非五地区赛事也受同一规则约束。

新闻正文及新闻/马匹自身地区归属不是本次赛事隐藏范围；马匹原始生涯统计仍保留，其公开赛事明细按比赛地区筛选。生涯记录优先使用 event 或 result.event 的已关联赛事地区；两者并存但不一致时不公开，仅两者皆无时使用自身 race_region。

## 历史数据

截止边界为比赛当地日期 < 2026-09-01。先盘点现有五地区 RaceEvent；已登记年度目录用于发现潜在整场缺口。日期为空且年份 < 2026 的记录纳入盘点，2026 年无日期记录单列待核，不能猜测所属月份。

现有赛事有赛果行不等于名单完整。分别核对年度/日期/身份、完整参赛及退赛名单、结果状态和关键字段；取消、停办、有效分场聚合与已确认重复记录不当作赛果缺失。字段空值先区分来源未提供、已采集但未映射、展示语义和真正漏采，不从其他字段猜值。年度目录中的 pending/held 不能单独作为确实举办或整场漏采的证据。

修复优先复用已有来源原件与缓存，再对确定的缺口使用现有官方、授权 API 或已准入专业来源；每个修复绑定赛事身份、来源证据、前值、后值和恢复面。未能补齐的项目逐项记录原因，不把“尝试过”写成修复完成。
