## 协调者提出的技术口径

4GiB 约束固定载体的大小及其内部全部构建数据，包括镜像副本、层、临时文件、控制数据和内部文件系统元数据；不自动扩容。它不能代表宿主实际物理新增也不超过 4GiB。宿主 ext4、虚拟磁盘分配、系统日志等公共开销单列，记录可取得的实际证据，不承诺尚无强制机制的物理总量硬界。

这些数字是协调者的技术提案，并非追溯为用户曾指定的要求。4GiB 只是可验证的条件候选，不保证足够完成工具链构建。
