## 实现与副作用边界

日历等级筛选、历史重点等级集合、本周G1焦点两路径共用可信等级判定。筛选在数据库分页前执行；展示标签和颜色通过相同 Python 解析器得到。两种展示开关下等级合同一致，距离等其他字段维持既有开关。

SQLite 在表达式编译时为当前物理连接注册一个确定性纯函数；没有应用启动 hook、全局连接 signal 或持久数据库函数，不写业务字段。PostgreSQL 使用原生 NFKC 与 ICU 大写转换的标量表达式，共享完整等级语法；JRA 赛事名后缀仅接受现有来源身份与官方目录 URL（默认 HTTPS/443），没有扩展信任范围。

PostgreSQL 每个物理连接首次使用表达式时读取 UTF8、normalize 函数及 und-x-icu collation 能力；缺失时该查询等级投影返回空代码，并记录错误。等级筛选/焦点因此可能为空，属于明确的安全降级，不能视作功能验收通过。首次探测多一次只读查询，重连后重新探测。实际目标生产环境能力尚未读取，不标记生产兼容通过。

没有 models/migrations 变更，没有全表 Python 后过滤，没有生产取数、修库、抓取、外发或开关操作。
