# 验证矩阵

所有验证在本地专用 PostgreSQL 或 CI 合成 PostgreSQL 16 上执行；不连接生产和第三方。
每条生产代码修改先获得目标行为 RED；fixture/导入问题只记作测试基础设施失败。

|条目|核心验证与边界|可捕获的错误修改|
|---|---|---|
|T1 回执|旧 v1 成功回执升级，32 字符限制，重试重放不重复，验证失败不留下部分收据/快照；实际 PG 并发一应用一重放|长类型、去幂等、缩小事务|
|T2 验收|既有五地区每区三赛事三年代共45；缺赛事/缺年代/重复目标拒绝；澳洲枚举存在不扩大；导出及同目标发现后选择|恢复全枚举遍历、漏选/换目标|
|T3 名单|原五条：完整字段应用、保留退赛、终局证据、临时结果、区域当日缓存共用；相关 provenance 缺失/错误来源/摘要/字段拒绝|放宽合同或错选来源|
|T4 PG合同|同号码不同 external ID 两行不丢失；只读审计不写业务表；合法漂移触发指定拒绝；非法直接写仍由现有约束测试保护|按马号覆盖、关闭 trigger、错误迁移允许|
|T5 翻译|缺占位符明确拒绝；只替换确认出现位置；合成 ID 合法|容忍占位符丢失、全局替换|
|T6 时间及fixture|固定 NOW 的 repair 成功与过期拒绝；同年/date；CSV 格式用历史年，当年 descriptor 缺失/不匹配仍拒绝|依赖实际日期、旁路当年闸门|
|T7 历史工具|design 中9项逐个替代，真实正式工具执行、fetch mock；畸形/缺文件/篡改/不同 cutoff/重试失败须拒绝或保留失败账本|无输入绑定、重抓成功 URL、吞失败|
|T8 路径与锁|根/server 均能找到 fixture；子进程真实 host 锁及共享日志、间隔|依赖cwd、进程各自独立锁|
|T9 公开页面|旧 region URL 301 且保留其他参数；关联记录仍在；全站文章分页不重复；QQ 原顺序；马匹三个公开提示与内部标签不可见|恢复旧筛选、数据删除、暴露内部等级|
|T10 运维|nginx 精确只读 allowlist/锁；可配置持久目录；发布恢复合同现有67项分两组|放开任意 compose run、失挂载、取消锁|
|T11 验证入口|空/错名/重复/>200 拒绝，实际执行集合等于展开集合；50项全部有归宿且零跳过；失败退出非零；CI scope 分支互斥|静默漏测、吞失败、意外全量|

先运行原50失败的分组 RED（每组不超过9项），再运行受改动 class 与必要相邻 module，
若 module 超200则按 class 拆分。实际扩展清单在执行前输出并保存。
不运行整个 stable 或 tests_legacy。与本轮无关的历史21跳过不计作修复，也不强制启用。
所有受影响用例/替代用例必须零失败、零 skip；其他受限平台用例明确记录并在 Linux 补证。

发布合同 49+18 项仍保留；代码 review 修改只复验受影响组，最终固定 SHA 跑完整的本次清单。
每批结果与 inventory 对账，禁止只有“没报错”而缺实际测试数。生产验证只读、不代替自动测试。
