## 最终行为

- 标题作为显式单元；正文按句末/换行边界组织约640字符的短单元。长句不硬切，保留原始字符和位置映射；每个核心区带邻近窗口。单元批量发送，每个单元必须有处理回执。
- 模型返回原名、类型和逐字上下文；服务端定位并还原原块跨度。同名多个候选不会默认取第一处；字段越界、定位歧义、重叠或遗漏单元形成明确反馈。
- 首轮只冻结无冲突的有效行。相互重叠的行全部待修；只对问题单元追加一次修复，已冻结行不可删除或重复。修复附有界只读邻近语境，禁止从非请求单元新增输出。仍不完整则待审，不进入翻译或自动发布。
- 实体修复单独记录，不消耗译文修复次数。发布前从首轮及修复回执重新计算并核对输入、完整性与快照；缓存只复用可独立完整重放的初始结果，不跨run复用补丁。
- 事件版本变化、重判后仍有重大新事实时开始新的实体轮次；旧回执与费用账证保留，不把上一轮完成状态误当成待修补丁。

使用现有JSON快照，无数据库迁移；既有预算、unknown、请求次数和生产开关守卫保持。仅context-v2实体路径采用新entity-units-v1输入协议，legacy路径保留。旧context-v2实体回执不能冒充新协议，提示词SHA与输入绑定会阻止不匹配缓存继续使用。
