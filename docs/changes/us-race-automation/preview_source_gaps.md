# 美国自然采集剩余缺口修正方案

## 目标与已观察事实

PR #303已发布，年度目录快照、现有页面和四应用验收通过。首次新版本自然到期批次中，Commonwealth Turf已自动生成18匹预想名单；本轮40目标已全部处理，36成功（35覆盖尚未核实、1预想名单）、4失败。本方案继续处理当前美国范围的实际来源缺口，不变更历史赛果、地区、公开自动化开关或QQ状态。

1. Pebbles、Manila的目录链接已发现，但当前来源策略缺少 `/pebbles-stakes`、`/manila-stakes` 路径；传输前被 `us_source_url_rejected` 拒绝。零网络的生产缓存回放确认根因。
2. Del Mar当前报名表中Native Diver和Red Carpet的报名文件单元格明确为 `-`，没有链接。解析器把这个尚未发布状态当成缺失链接错误。原件SHA256 `dd75474a1837ebbdbed4b7dfaeb24d786a8ddceccc3c33627fb4e046ab4c97cb`，采集时间 `2026-11-12T10:20:03.155727+00:00`。

3. Colonial Cup的NSA赛事索引 `https://nationalsteeplechase.com/racing/` 返回HTTP403，零网络缓存核验确认失败入口。不能将访问失败当作未发布，也不将网页搜索可读视作生产自动采集通过；本轮保留真实失败，独立记录来源访问阻塞。

## 最小实现

- Del Mar仅在报名文件单元格明确为 `-` 且该单元格没有链接时跳过未发布报名行；已发布链接继续严格校验。空白、文本Noms却无链接、重复链接和非法URL仍报错，不能把结构错误泛化为未发布。
- 在现有美国来源策略中补齐两个明确赛事页面路径，不加入根路径、不扩大主机或地区。采集器已有的严格USRacing路径正则继续生效。任意新增来源路径仍须有明确范围。
- 全局policy摘要变化会影响当前220条v2登记（美国111、法国60、日本43、香港6）。使用既有 `rebind_multisource_enrollment` 完整换绑摘要闭集；不重抓历史来源、不重建身份或改写赛果。
- `run_us_release` 复用现有整包事务、库内提交收据、幂等及精确恢复，仅允许在非空rebind清单时使用空items；空items+空rebind仍拒绝。空历史archive绑定为合法的空documents文件，执行中不得调用历史采集器。
