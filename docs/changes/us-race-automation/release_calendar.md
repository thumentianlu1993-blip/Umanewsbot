- 将真实TOBA 2026 HTML及绑定清单放入本包专用目录，以只读卷挂载至 `/run/race-data-sync/us-calendar`。原件采集时间为 `2026-11-11T19:45:10.803577+00:00`，SHA256为 `6e819d6300b04623df3fc779c6d7fd0622be9cd1e6bfe9771d78af96833e3f4b`，2024001字节。
- 清单SHA256为 `5b2f52734e4537c53373389cd056228462ac2888128b28fc12675982b23b4b11`。四应用增加 `RACE_DATA_SYNC_US_CALENDAR_SNAPSHOT_FILE=/run/race-data-sync/us-calendar/index.json` 与该SHA配置，发布版本标记随镜像切换。
- 取得生产发布锁，核对当前镜像、配置、schema和磁盘；流式载入候选，执行只读启动和真实快照入口核验；暂停Beat并排空两个worker，再重建web、验证健康及153个页面、重载Nginx。最后重建两个worker并确认就绪，再恢复Beat和核对四应用。
- 无迁移、无批量数据写入/删除或历史重导。既有获准自然调度继续产生候选、赛果和检查状态；地区、赛事范围、功能开关和QQ状态不扩大，QQ仍关闭。整库备份不作为本包前置。
- 只读检查确认新增快照请求零网络调用、原始时刻不变；其他来源仍遵守现有许可和共享预算。发布后核对公网代表页、自然任务的实际检查及来源状态，明确记录尚不可观察的正式卡/赛后节点。

## 回滚与验收边界
