# 美国3/4/6实施设计

## 结果目标

把已通过的美国采集层接到现有公开与自动更新链路，并修复线上回归确认的展示缺口。
第3项：赛日重点5分钟、普通10分钟取当前卡/临场/赛果，赛后7天内继续检查更正；未知开赛时刻不猜填。
第4项：补表自动发现、全年赛场映射、任意日期窗口；不再依赖按某场填写的program_sources。
第6项：按明确身份一次写入当前全范围、启用登记与阶段推进，验证重复执行、更正、自然调度及公开字段。

## 最小实现

1. `us_venues.py`集中保留来源赛场代码、明确名称别名与IANA时区。覆盖年度目录实际代码，未知代码明确报错；不用美国统一时区，也不以模糊匹配建立生产身份。
2. 扩展既有纯解析器/collector：DRF目录、SL日目录、ABR与其明确文章/出马表链接自动发现；URL先过严格允许列表。来源标题、日期、场次、全名单与计数继续核验。保留开赛时刻的来源时区、奖金、参赛条件、场况和比赛用时/分段；DRF无AM/PM的OFF AT不能直接猜成24小时。
3. `us_race_source.py`把单场多份已核验原件转成现有SourceRoute observation。按时区分别配置受审route，provider为`us_racing`，源ID为代码/日期/场次；源名与原始身份不由显示名反推。结果保留裁定名次、物理冲线顺序、同着/退出；着差统一为距前一匹物理完赛马并标注，比赛时间不复制给所有马。净赔率明确标注，不套香港或十进制口径。单场有界取数复用共享快照/host预算/熔断，支持PDF二进制，原件SHA与实际抓取时刻保留。
4. `us_public_fields.py`向现有card/result writer提供源字段契约与公开metadata。新写入负重明确lb，赔率明确美国净赔率，稳定马号/身份映射、状态和来源可追溯。修复显式时间与synthetic距离解析。赛果来源重建的名单标为“参赛记录（赛果来源）”；赛前候选不冒充最终卡。仅在有证据时展示奖金、条件、场况、比赛用时/分段。
5. `us_pre_race.py`复用既有候选/租约和manual/owner检查，保存报名、预想、临时卡。单独US开关默认关闭，接现有race_sync_v2队列，分钟级Beat只挑due目标；窗口内早期3h/临赛1h/赛日5或10分钟。完整卡进入已有multisource claim。来源旧日changes拒绝，不因名单缺席推断退赛。来源未发布和传输失败分开，不把失败冒充空成功。
6. 既有`calculate_multisource_next_poll`增加仅US的赛日5/10分钟分支，已确认赛果继续现有更正节奏直到T+7天；无时间但有日期的已确认场也不能停止更正。相邻自然tick证明真实执行，隔离时钟测试覆盖T前后、七天边界、变更及重试。不声称尚未发生的完整七天自然观察已完成。
7. Glen Cove采用显式`RaceEvent.division_parent`可空自关联，子场次不另建假赛事系列，旧547保留年度入口和系列。两个子场独立来源身份、日历与结果；父入口链接两场，不当作第三场出现在日历和自动发现中。历史冠军按父系列聚合两场。原series/edition唯一约束保持；新增字段迁移从当前0082分支产生，并在主线合并迁移分支，不带入未部署的其他功能迁移。拒绝跨年/地区父子、不允许环和多层。无需删除旧事件或旧URL。
8. `us_release.py`与只读/事务dry-run命令：精确manifest绑定候选SHA、policy、原件、赛事/系列/owner/行数据baseline；复用现有锁顺序、身份键、attach_multisource_observation、claim_multisource_events与run_multisource_claim。无日期not-run单列可审动作。计划外、人工锁、身份冲突或字段缺口拒绝整包；幂等收据。备份覆盖本次写入及控制面，提供after-image校验的定向恢复；回滚保留新增列，不逆向schema或覆盖他人新增数据。

## 验证顺序

- 真实线上缺口先RED：显式时间、synthetic距离、条件奖金、净赔率、名单标签、Glen Cove两个分场与旧入口。
- 原件parser/发现RED→GREEN：全年已观察赛场，跨午夜/夏令时，SL缺席时实际链接补源，缺字段/名单不符拒绝；网络测试只使用fixture。
- 合成PostgreSQL端到端：档案准备→强身份→候选→登记→正式卡→赛果→更正→公开；相同输入重复执行无重复赛事/结果，人工锁与baseline漂移拒绝；两分场互不覆盖。
- 隔离恢复/完整原件重放按本次范围运行，固定候选镜像验证，独立只读review返修闭环，远端影响范围CI，不机械全量CI。
- 发布包准备后只读生产dry-run/基线验证（不会运行会写候选的事务dry-run到生产）；G2/G3获准后备份、一次发布/数据apply与启用，观察自然调度和全部当前可观察公开目标。

实现中若发现来源本身不发布的字段，单列事实与具体赛事，不能扩大抓取到Equibase或伪造数据。

## 首轮审核落实

- 新增美国route会改变全局policy digest。发布manifest同时列出既有日/港/法登记的精确ID及新旧policy/route digest，复用既有rebind；先暂停领取、使在途claim失效，再原子换绑。备份/after-image恢复包括这些控制面记录，恢复后验证各地区准入，不能只备份US。
- 分场子记录race_series为空，经division_parent取得系列语义；年度父容器退出occurrence身份解析及候选匹配。首次登记和重放均使用代码/日期/场次强键，测试父记录已有受审系列别名时第5/8场仍独立。
- claim_multisource_events及内部历史准入同步加入us_racing/united_states；按manifest逐场临执行领取，收集每一目标的结果收据，避免批内等待消耗租约。零领取/部分完成均为未完成，测试21场及T+7以外的受审历史回填。
- 最终名单冷启动核验：adapter保留DRF/NSA完整结果原件SHA、完整计数及独立补源名单证据；fetch核验已入库snapshot对应的解析结果和horse identities一致后才允许roster_complete。不能仅接受布尔值或要求不存在的历史早期卡。
- 更正契约只接受来源正文中明确的CORRECTED/REVISED CHART或NSA更正说明，并绑定原件SHA与原始标记文本进入correction_marker；同一身份/名单需重新通过。没有明确标记的异值official进入冲突，不能按抓取时间或内容变化自动升级corrected。合成有标记fixture覆盖首版→更正revision→重复幂等，无标记异值保留冲突；真实来源尚无更正样本时明确该验收局限。
- US赛前finish_pre_race独立调用同一US due策略，重点定义现有priority=P0/P1，其余P2；赛日5/10分钟，前一天1小时，更早3小时。连续claim/finish及传输失败覆盖间隔，重试有界且不混同not_published。分钟Beat与完成路径一起测试，单场执行耗时保留在实际验收报告。

## 数据包与恢复合同

数据清单包含153条赛事：151个来源目标、Glen Cove年度入口及Turf Monster未举办说明；142条既有记录、11条新记录，计划111场共1071条赛果/退赛记录。新增全局policy同时列明109条既有日/港/法登记换绑，不抓取或重写这些地区的公开数据。
