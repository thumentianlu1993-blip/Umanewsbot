# 美国赛事采集与更新

## 目标和现状

沿用 P02：验收 2026 年 9—12 月所有项目范围内美国 G1/G2/G3（平地与障碍）及人工指定赛事，实现支持任意日期。报名、预想、出马表、临场变更和赛果分别建证据；一个合格完整来源即可。

2026-11-11 来源研究初报 TOBA 142 场平地候选；实现严格去重后确认应保留143条来源记录（Glen Cove同日第5/8场同名待核），另有NSA 8场障碍候选，尚非生产分母。Bob Hope 在 TOBA 为 Listed，在 Del Mar 为 G3，必须列冲突。TRA 北美端点明确需要附加套餐；Equibase 直接自动访问不纳入当前实现。研究原件位于本机 runtime/us-source-research-20261111，不含凭据。

## 连续实施范围

1. 建立可运行的只读采集层：TOBA 年度赛程；NSA 目录、条件册和结果 PDF；Del Mar 报名目录/PDF、日期出马表和临场变更。保留来源、摘要、阶段、时区和字段缺口。
2. 用既有 SourceRoute URL 边界接入 Del Mar 单场发现与标准 observation；报名/未定稿卡不得冒充 final racecard 或 result。获取与解析分离，真实 HTML/PDF 可无网络回放。
3. 提供 verify_us_sources 只读命令：赛程清单、逐源采集、逐场覆盖与错误报告；默认离线回放、显式有界 HTTP。采集成功不等于身份已批准、生产已导入或公开完整。
4. 来源覆盖、缺字段、生产身份对账解决后，冻结发布 manifest，接入现有候选写入、生命周期、5/10 分钟调度及七天赛果更正。不得伪造许可、猜测字段或放松完整性。

当前首先完成 1—3；4 是美国总体交付剩余工作，来源验收决定可发布范围。没有完整主源时，生产全量更新验收明确不通过，不宣称美国修复完成。

## 验收

- TOBA 按年/月/级别过滤；not run 无日期单列，重复 DOM 不增数，相同身份冲突不静默覆盖。
- NSA 条件册六场秋季分级赛，九月结果补两场；历史冠军不产生新赛程。保留非完赛；逐匹赔率/着差缺失如实列出。
- Del Mar 报名 11 匹、卡 5 匹；PGM/PP 分开，磅和赔率类型明确，未 final 提示保留。日期/赛名/场地不一致拒绝。
- 变更正文日期匹配指定日，不把默认旧赛日当今日；不推断缺席即退赛。
- HTTP 不跟随未验证重定向、不抓 Equibase；失败/缺数据不返回完整成功。
- 无迁移、生产写入、订阅购买、对外消息或默认开关变化。
