# 验证清单

- 普通新闻worker长任务下，赛事控制、临场取数独立可执行；重试优先且幂等，过期claim不能写入。
- Beat及直接dispatch路由一致，新增worker订阅与Compose/发布服务集合一致；原非赛事任务维持原队列。
- 周日rush无剩余入口，普通netkeiba计划保留。
- 日预算已满：临场结果仍可取数；普通发现拒绝；磁盘或响应上限仍拒绝；额度耗尽后台退避到重置时点。
- 任何已准入绑定来源的冠军支持完成状态，包括部分资料；无冠军、猜测、错场、过期claim、取消/延期、人工锁不得错误推进。
- T+30、错过开赛、date-only跨日均不凭时间完赛。
- 正式结果发布依然要求完整名次/身份与所有非完赛状态；部分状态成功后继续抓完整表。
- 同一正式结果仅抓取时间/来源原文摘要不同不生成伪更正；真实结果变化仍受更正证据保护。
- PostgreSQL事务/幂等与来源真实缓存离线回放；按影响范围CI与独立review。
