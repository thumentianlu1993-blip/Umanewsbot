# P04-1 赛事名称关联

## 范围

用户于 2026-11-15 要求将赛事马匹、骑手、练马师名称关联到已收集的 HKJC 中文名。
HKJC 本身是官方译名依据，不再要求第二个独立来源批准其中文译名。
本轮在当前独立 worktree 实现只读名称解析和离线匹配演练；不修改原始字段、实体 ID、
马匹履历发布状态、术语库或采集范围。共享主线和生产操作引用根 AGENTS.md。

## 规则与接入

- 从既有马名包及新版人物包构建版本化目录，保留名称条目 ID、HKJC 来源与输入 SHA。
- 仅接收有完整中文的 horse/jockey/trainer；HKJC 繁体原值保留，展示按既有 t2s 规则转换。
- 同一记录的当地原名与拉丁名称形成显式别名。不按中文相同合并实体，不猜日文音译。
- 标准化大小写、全半角、空白、拉丁重音及常见姓名标点；马名仅去已知产地后缀。
  法国来源的“姓＋首字母”只在后缀明确全为首字母时交换顺序。
- 人物全名可生成保留姓氏的首字母形式；缩写命中同时检查官方缩写与全名候选。
  仅姓氏、缺失名字、多人联名不生成缩写。多个候选译名或不兼容全名保留原文。
- 全名和显式多语言别名跨赛事举办地查询。语言是来源写法，举办地不是人物国籍。
- 该目录仅负责中文显示，不是实体消歧结果。同名冲突不通过优先级或举办地强选。
- 复用前轮同场/同马/同角色 JRA 行引用，补入外籍人物日文显示别名（如 C．ルメール）；
  不称为其当地原名。缺字私用区中文不进入目录；见习/让磅注释从显示名去除，原值保留。
- 通过配置中的文件路径和 SHA 绑定启用；默认关闭。读不到目录或 SHA 不符恢复既有展示。
  目录未命中时沿用既有正式术语解析，避免本轮四地境外赛卡覆盖不含香港本地名称时丢失已有译名。
  目录冲突强制保留原名，不让旧术语优先级掩盖冲突。无可靠原名的汉字马名仍遵守已有马名策略。
  新目录全面展示依赖现有 RACE_INFORMATION_NORMALIZED_DISPLAY_ENABLED=true。
  关闭目录路径即可恢复既有展示；无迁移、无批量生产数据写入。

## 验证

先取得最小 RED，再覆盖全名、英文缩写、同姓冲突、日英别名、角色隔离、马名产地后缀、
异译、未知名称、坏目录和展示开关；自动测试仅用本地 fixture。
线上名称单独用 PostgreSQL 只读事务导出，15 秒语句超时，只做本地演练。
代码审查与译名来源复核是不同事项，前者按仓库原生流程执行。

## 65 组人工裁决后的规则

2026-11-15 用户完成全部65组审阅，授权应用裁决并在同一快照重跑。
`reviewed_decisions.json` 保存每组裁决、来源记录ID、已确认名称组和原始队列SHA，
`apply_hkjc_name_reviews.py` 只接受与裁决绑定的基线目录SHA；原始HKJC字段与各条证据不删除。

- 已确认同人的拼写变体共享名称组，缩写可归一；组外同首字母全名继续冲突。
- 荣进快蹄、真机伶等选定译名替换旧译名；用户淘汰的中文不进入名称别名。
  原日文名即使字形不同仍保留；伊藤正徳、菊沢隆徳等不按通用汉字替换规则改写。
- 同名不同马分别保存产地、生年和已有父母名，不用性别变化拆分同马名称组。
  显式生年或年龄与赛事年可消歧；同生年仍冲突时须产地或血统。
  产地只读马名后缀或显式身份字段，不从举办地推断；字段相互矛盾时保留原名。
  缺失字段不能作不符剔除，也不能让没有正向证据的剩余候选被选中。
- 不同人物的缩写继续分别保存；可接收明确完整姓名上下文，无该信息时不猜。
  Richard Hannon父子按获准训练身份年份区分：向能截至2013年，向礼伦自2014年。
- 展示请求包含名称上下文，防止不同赛事/年份的同名结果互相覆盖；历史冠军使用winner_year。
  展示适配器不猜测raw_payload字段。普通行复用明确赛事年；历史快照缺winner_year时不使用父赛事年。

当前演练快照没有年龄、生年、血统或具体日期，故只应用名称本身和可确定的赛事年。
不为本轮重跑扩大生产查询或第三方抓取；缺上下文的重名保留到后续数据补齐。

## 正式接入准备

用户要求开始使用后，将原SHA绑定的完整目录作为静态资料纳入server/stable/data，随固定镜像发布；
配置仍默认关闭，发布包显式设置路径与SHA。实际公开页面测试覆盖日历、详情名单、赛果和历届冠军。

真实目录发现官方中文栏残留豊/撃两种日文字形，展示时分别用丰/击；原条目、原名别名和目录SHA不改。
字形依据见[OpenCC原始对照](https://github.com/BYVoid/OpenCC/blob/master/data/dictionary/JPShinjitaiCharacters.txt)。
只纳入本目录实测的两种字，不采用整套日文旧字体转换（其对郎/研/晃等会产生不适合中文显示的异体）。
不将此字形规则用作身份合并或源日文改写。
