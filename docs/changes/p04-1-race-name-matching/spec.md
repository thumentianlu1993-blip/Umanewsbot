# P04-1 赛事名称正式接入

2026-11-15 用户要求开始使用已收集及审阅的名称，使赛事模块马名和人物名尽可能显示中文。
本指令覆盖本轮实现范围；共享主线及生产交付按根 AGENTS.md。

## 行为

- 赛事日历优胜马、详情页出马表、赛果、冠军摘要及历届冠军共用只读名称解析。
- 马匹、骑手、练马师使用 HKJC 官方中文和已确认的65组裁决；明确别名及无歧义缩写跨举办地区查询。
- 重名、缩写冲突和缺失目录记录保留原名；不猜同名身份，不扩充90条未经确认的中间名建议。
- 官方中文按简体展示；原日文、繁体原件、业务原始字段及实体关联保持不变。
- 开关关闭恢复既有展示。目录读取失败或SHA不符不得采用未绑定内容。

## 非目标

不重新抓取或扩大四地赛卡，不生成新译名，不修改新闻内容、马匹实体及履历发布状态，不启用公开自动化。
目录外仍可使用既有正式术语。名称命中量不是全站数据完整性或实体归并数量。
