# 实体归属、幂等去重与候选选择

用户已批准先离线修复三项实测问题，再对原三篇做有界实体复测，通过逐条复核的文章才继续翻译/审校。沿用独立worktree/分支，人工门禁统一引用根AGENTS.md；不合并部署或扩大来源范围。

entity-units-v2保留标题、短单元、原文映射和一次局部修复。定位优先使用声明核心区内的唯一位置；无核心位置而窗口内只有一个位置时，程序按原文起点归属同块的正确单元。初轮所有单元均在请求范围；修复请求明确包含错误回执单元及已观察到的未决候选/冲突的实际归属单元；只允许这些请求单元新增提及，非请求单元只允许与已冻结行完全相同的幂等重复。不得跨块推断、全篇按名称套类型或默认选首次。

同block/start/end/text/type的重复行幂等合并；类型不同、长短边界重叠继续待修，同批冲突整体排除，不选先到者。未知字段/计数/回执覆盖限制保持。

歧义问题带稳定issue_id及candidate_id；候选含原文位置、上下文、正确单元、类型与已冻结状态。候选超过128个直接阻断，禁止截断后标完整；位置枚举的集合有界。修复输出仍覆盖请求units，可为遗漏/字段错误返回原文行；另显式返回decisions，每个歧义issue必须恰好一个decision，picks选择候选ID与类型，空picks明确表示该问题没有专名提及。不能缺省遗漏问题，不能引用未提供ID；选择仍受同样的类型/重叠/归属校验。每个接受的提及保留原文上下文；发布通过原始首轮+修复回执重建，不信任快照或模型自报complete。

提示词针对所有命名类型区分普通用词、等级、角色称谓与明确命名。语义案例含普通用法、明确命名、证据不足，不硬编码字符串黑名单；确定性程序只证明位置/结构，不能证明语义正确。

验证先RED/GREEN覆盖正确归属、完全重复、同名不同位置/类型、边界冲突、未知候选、缺失决策、原文篡改及跨worker稳定性。5份旧回执只作离线诊断，旧实时评分不改；候选选择的合成响应不能冒充模型成功。定向8模块及独立复审完成后冻结新的真实包，原3篇最多6次实体调用；费用与旧unknown结转绑定执行包，禁止重发旧请求。后续阶段只对本轮逐条复核合格文章执行。
