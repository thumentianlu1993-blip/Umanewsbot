# 赛事日历默认比赛日窗口规格

## 背景与根因

公开入口为 `GET /races/`，由 `stable.views.public_race_calendar` 调用
`_race_calendar_queryset`。当前无 `year`、`q`、`cursor` 时：

1. 以 `timezone.localdate()` 取得今天；
2. 查询今天前后各 30 个连续自然日；
3. 按 `local_date` 升序；
4. 在赛事对象层截取前 40 场；
5. 再从这 40 场生成日期栏。

因此北京时间 2026-07-27 的下界恰好是 2026-06-27；赛事密集时前 40 场可能在
2026-07-19 已耗尽，日期栏便停留在 6 月 27 日至 7 月 19 日。根因不是硬编码日期、
UTC 偏移或页面缓存，而是“自然日范围 + 赛事行数上限 + 从已截断赛事反推日期栏”的组合。

## 范围

- 默认入口的锚点比赛日选择；
- 当前有效筛选条件下最多 11 个实际比赛日的平衡窗口；
- 默认日期栏与默认赛事列表使用同一公开资格集合；
- 显式浏览模式、筛选、搜索、时区、空状态和查询预算回归；
- 保留现有跨月/跨年显示、响应式布局及 G1/G2/G3 徽标尺寸。

## 非目标

- 赛事生命周期、Celery/Celery Beat、`race_live_worker`；
- 出马表、赛果同步、官方复核或生产赛事数据；
- 赛事资料归一化、赛事时间转换、首页“近期赛事”；
- 赛事详情页年份切换、整体视觉改版；
- 新增数据库字段、迁移或日历页面缓存；
- 新增一个此前不存在的 `date=` URL 协议。

## 公开资格

比赛日和该日赛事必须共同来自以下基础集合：

- `RaceEvent.visibility_status == published`；
- 排除作为 active canonical product link 的重复底层赛事；
- 应用当前 `tab`（默认重点）、`region`、`grade`、`when` 筛选；
- `local_date` 非空。

现状不以 `data_quality_status` 作为公开门禁，本任务不改变该产品语义。日期栏不得由隐藏、
草稿、active canonical duplicate 或不符合当前筛选条件的赛事单独制造日期。

## 默认模式与显式模式

仅在没有以下显式浏览意图时计算新默认窗口：

- 合法的 `direction=past|future` 与 `cursor=YYYY-MM-DD` 组合；
- `year` 年份筛选；
- 非空赛事名称搜索 `q`。

现有产品没有 `date=` 参数，日期栏链接是页内 `#race-date-YYYY-MM-DD` 锚点。既有显式日期
语义是 `cursor` 分页边界；本任务保留其行为和筛选参数，不把历史 cursor 自动改写为未来
默认锚点。非法或不完整 cursor 不视为可靠显式选择，安全回到默认模式。

`year` 和 `q` 继续用于跨年度查找，不套用“今天附近 11 个比赛日”，避免历史搜索结果被
默认窗口隐藏。其日期栏继续由实际返回的赛事分组生成。

## 默认锚点

“今天”必须显式按 `ZoneInfo("Asia/Shanghai")` 计算，不依赖服务器系统日期或隐式 UTC。

在当前有效 `tab/region/grade/when` 集合中：

1. 今天存在公开赛事：今天为锚点；
2. 今天不存在：未来最早比赛日为锚点；
3. 没有未来比赛日：最近历史比赛日为锚点；
4. 没有任何带日期公开赛事：无锚点，返回正常空状态。

## 窗口规则

- 先选择锚点前最多 5 个比赛日、锚点、锚点后最多 5 个比赛日；
- 某侧不足 5 个时，从另一侧按离锚点由近及远补足；
- 最终结果升序、唯一、包含锚点且最多 11 个；
- 全部可用比赛日不足 11 个时只展示实际数量；
- 不插入任何无赛事自然日；
- 默认赛事列表只查询所选比赛日，日期栏中的每个日期必须至少保留一场同资格赛事；
- 保留现有最多 40 张赛事卡的页面上限；高密度窗口先为每个日期保留一场，再按原有时间顺序
  填充剩余额度，不让第 40 场之前的密集日期吞掉后续比赛日。

## 筛选与搜索语义

- `tab`、`region`、`grade`、`when` 参与默认锚点和窗口计算；
- 筛选后今天无赛事时，在筛选结果中寻找未来最近比赛日；
- 筛选结果完全为空时返回 200 与明确空状态；
- `q` 是跨年度赛事名称检索，继续绕过默认锚点；
- `year` 同样继续绕过默认锚点；
- 切换筛选时清除现有 cursor/direction 的行为保持不变。

## 验收标准

- 默认日期栏满足锚点及 5+1+5 平衡规则；
- 默认页面不再由固定自然日下界或前 40 场决定日期范围；
- 空库、空筛选、仅历史数据均返回 200；
- 显式 cursor、年份和搜索结果不被默认锚点覆盖；
- 北京时间跨日后新请求立即使用新日期；
- 同一个上海日期同时驱动锚点、赛事状态、“今天”高亮和 aria 标记；
- 默认模式在横向日期轴中把锚点滚动到可见区域，未来锚点也可识别；
- 无新增页面缓存、迁移、数据写入或视觉回归。
