## 来源覆盖的真实边界

NYRA、Sporting Life、ZEturf、NAR使用已保存公开页面的缩减结构样本；Racing Post使用本轮浏览器实测DOM结构及公开事实构建合同夹具。普通HTTP请求Racing Post返回406，浏览器可读不证明后台可抓取；发布预检若仍为406，必须记录对应卡的覆盖缺口/更新延迟，或另行冻结已验证的同场替代来源绑定，不启动绕过限制的采集服务。

本轮测试中连续两次到期检查为冻结时钟/模拟网络验证，不是生产自然周期。线上自然tick、赔率变化、双域名验收仍待实际发布后执行。
