## 实现边界

仅在原始名次为空时，读取同页唯一的 `Pla. / Horse No. / Horse / Incident` 表。要求马号、官方 horse ID、马名和空白事件表名次完全一致；链接必须为 HKJC 官方马匹路径；重复、缺失或冲突均拒绝。事件报告必须完全符合明确的兽医退赛句式（可带同马的再次出赛前兽医检查说明）、退赛日期不晚于比赛日期，且主表不能同时出现跑位、完赛时间、赔率或差距证据。未知的非空状态仍拒绝。

有效时只将规范状态设为 withdrawn，名次继续为空；不将原页改为 WV。原始空值、来源 URL、原件 SHA、马匹身份、退赛日期及报告文字保留在状态字段证据中。原有完整名单、身份、权限、人工锁、正式确认及公开门槛保持。
