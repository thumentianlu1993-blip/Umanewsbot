# P01 同批真实新闻问题修复

用户授权按已解释方案修复，先复用已有结果做离线回归，再复测同一批五篇真实新闻的质量、耗时和成本。
基线为已部署e6c47a98及本线程文档提交d3235ca0；生产P01关闭。原始试跑见相邻p01-live-pilot-20261114/report.md。

范围：中性敬称新增性别、同人全名/简称、血统关系、通用地域及赛马术语、月份缩写与文字分数、
选稿的原文引用协议、审校重复载荷和深度输出预算。保留原失败与费用，不把AI辅助参考称为人工gold。
不新增来源/样本，不维护马匹库，不新增迁移，不批改历史新闻，不启用公开自动化或QQ。

通过条件：
- 本批真实错误及相关正反例离线回归通过，兼容旧协议和发布时证据重放。
- 同样5篇、固定模型/策略、原文摘要不变，取得完整译文；逐段原文核对无已确认的关键事实新增/遗漏、角色互换、
  血统/称谓错误，通用词正常中文化；未确认专名仍保留原名。预设事实20项逐项记录，摘要也检查。
- 选稿返回满足协议；客观缺少身份或新闻类别支持的稿件必须合法uncertain，不能为了全通过编造ID、年份或放松身份。
  这类稿可在仅评测的诊断分支继续翻译，但不算发布资格；即使翻译通过，也不能声称五篇自动发布通过。
- 同批至多50次新请求、总保守预算2美元、单篇0.50美元、一次实体修复和一次译文修复；结果不明停批，取回同operation收据后才续跑。
- 报告各阶段/各篇/API合计、首请求至末响应窗口、token及费率折算（非供应商账单）。性能目标：无120秒超时、
  无输出截断，每篇API累计不超过180秒，整体不超过600秒；单篇成本上界0.50美元。目标是此次小批工程验收，非生产SLA。

修复实施/离线通过/真实复测/合并部署/启用分别记录；交付依据根AGENTS.md。
