# 第二阶段验收矩阵（待实现）

下列是行为验收要求，不是已经通过的测试。自动测试使用固定时钟、fixture/mock、本地隔离 PostgreSQL/Redis；阻断外网，清理环境并 mock dotenv 加载，不依赖 DOTENV_DISABLED。真实生产核验另用有界只读脚本，不混入自动测试。

| 编号 | 场景 | 必须成立的结果 |
|---|---|---|
| D01 | 公开赛事没有 enrollment/source ID | 在分母中；内部身份复核有责任和时间；无伪造 ID、网络请求或 owner 抢占 |
| D02 | draft 未选入/显式选入 | 前者不自动抓取；后者可跟踪但公开仍不可见；撤回选择有记录 |
| D03 | 两个名字相似，强身份不同；同场多个来源 | 前者不合并，后者复用 canonical；强身份并发登记只有一个目标 |
| D04 | JRA 身份成立，名单已见而马号未公布 | 身份/赛时能力独立可用；完整赛卡/结果 writer 不调用；只授 result 的 route 仍不能写赛时 |
| D05 | 精确赛时到 T/T+30，无发车/结束证据 | 只改变 clock_hint/检查优先级与 SLO，不写 running/finished；旧直接 apply 也不能绕过 |
| D06 | date-only 当地午夜、北京跨日及 DST 模糊时刻 | 不伪造赛时或完赛；当地赛日不混入北京时间今天；歧义不自动选择 offset |
| D07 | 有发车信号、结束信号或完整合法结果 | 依证据转态；赛后补入可直达结束，无虚构赛中 transition |
| D08 | 部分赛果、暂定全表、完整参考、正式、更正 | 成熟度/完整度分别判断；参考不冒称官方；只有满足对应现有合同的版本公开 |
| D09 | 跌倒/退赛/取消资格/平手 | 不产生虚假官方名次；完整 runner 守恒、真实并列名次与展示顺序可并存 |
| D10 | 改期后旧 task/claim/HTTP 响应迟到 | schedule generation 失效；旧 observation 可留审计，零旧投影、零新 claim 误释放 |
| D11 | 取消/延期后迟到结果或新赛时 | 不自动解除事实终态；明确更正/新赛程走证据仲裁；延期保留复核 |
| D12 | owner 变化、人工锁、source-set 换代发生在抓取中 | 末端重验失败，零业务写入；幂等重试不改新 lease |
| D13 | 当前 fetch 权限到期但原 publication 有合法证明 | 零新请求/写入；历史正式版本仍可见，详情/列表一致 |
| D14 | publication/source/terms/binding 撤销或公开开关关闭 | 历史证明仍保存，但立即不可见；缓存不能遮蔽撤销 |
| D15 | 11 场旧证明之一缺失/摘要不符/当时已过期 | 保持 blocked、明确缺项；不能用今天的 policy 或改 owner 越过 |
| D16 | 无关 route 更新/相关 route 更新/全局撤销 | 无关目标不被无差别冻结；相关目标按受审 CAS 换绑；撤销实时阻止执行/公开 |
| D17 | today/tomorrow 窗口关闭或 T+7 后仍缺结果 | 不调不支持历史的接口；保留缺口、合法替代或内部复核，不从分母消失 |
| D18 | claim 提交后 broker 失败、发送后收据未提交、重复投递 | outbox 可恢复；同 generation 幂等；只有一条有效业务投影 |
| D19 | 两个 selector/worker 同时抢一个能力；worker 崩溃 | 现有租约/CAS 控制；过期后合法重领；不依赖裸永久锁 |
| D20 | celery 中 100 条慢新闻，race_sync_v2 慢抓取 | 控制队列按容量合同执行；普通消息未被删除；Beat 与直接调用路由一致 |
| D21 | Beat、控制 worker、Redis 或 DB 单独不可用 | 队列外探针在 10 分钟阈值标 stale；不伪称 next_due 已执行；告警失败可诊断 |
| D22 | 同一 snapshot/now 重复决定，或影子比较连续运行 | 字节规范化后的决策一致；零来源请求、零业务写入、零邮件 |
| D23 | 执行成功但资料无变化、空响应、解析不全、HTTP 200 | 分别记录结果；last_attempt/last_success/last_data_update 不混用，缺口不错误闭合 |
| D24 | 多 blocker、人工暂停、取消、重复 canonical | 诊断不丢次要 blocker；暂停有复核；取消可结束主动抓取；重复不重复计数 |
| D25 | 九地区各合法 zone 与 US/AU/中东多 zone | 允许的赛场时区精确验证；未启用 route 仍只读展示；不把地区展示当抓取许可 |
| D26 | 旧时间推断 finished vs 合法完整历史结果 | 前者不冒称证据确认，后者不被统一降级；历史审计不回写 |
| D27 | 新 schema 并存旧应用、暂停新 cohort、重新接管 | 兼容读取；不存在两个写入者；恢复按新 generation 而非重播旧 claim |
| D28 | 10578 量级全目标、近期密集到期、收据清理 | 查询次数有界，无按场 N+1；运行时间/内存满足资源预算；被审计引用记录不删 |

生产验收按切片做：2A 固定 11 场逐场 proof/公开差异与匿名详情；2B 同时刻影子与旧决策差异清单；2C 真实已授权来源按能力样本；2D 至少两轮自然控制周期，以及实际赛前→赛后→更正的生命周期验证。无法当天等到真实赛后/更正时保留待验收，不用离线 fixture 代替自然闭环。

第一批七场恢复（52 行、两条跌倒）和 JRA 103–107 已有正式闭环作为回归样本；不重复执行其生产恢复。日期敏感统计记录 as_of，初次 44 个缺口不写成永久固定预期。
