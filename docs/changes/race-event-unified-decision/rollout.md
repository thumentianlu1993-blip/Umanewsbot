1. 只读固定 11 场 inventory，生成可证/缺证清单；最小历史公开兼容独立实现、review、演练与发布。缺证对象保持受限。

3. 在既有已授权 JRA 小 cohort 验证能力拆分、事实语义和地区时区，不扩大 provider/region。包含 date-only/缺马号等离线反例和合法真实样本；下一场真实结果未发生时明确待验。
4. 完成 outbox 新 schema、race_control 新服务、独立心跳探针及发布/恢复合同后，再切换该 cohort 的唯一调度入口。事务绑定 owner/enrollment/schedule/source-set generations，旧任务全部失效。
5. 自然周期和完整业务链通过后按能力/地区扩大；旧入口只有在查无活跃依赖、公开读兼容稳定、恢复方案验证后退役。旧 race_live 7543 条遗留消息始终不自动消费/删除。

## 停止与恢复

- 发现第二写入者、撤销无效、错误公开、generation 越界、任务重复投影或恢复证据不完整：停止新 cohort 调度与相关公开变化，保留来源及审计，按实际故障生成前向修复。
- 影子失败可停影子并保留原链路；2A 兼容错误可停新兼容读路径，恢复旧受限展示，不删原结果或证明。
- 单纯暂停新 fetch 不撤销合法已发布版本。需要撤销公开时使用现有明确公开/来源撤销控制并留审计。
- schema 迁移后不直接降级应用/全库覆盖；使用该版本受保护恢复合同或同 schema 前向修复。恢复旧业务规则前须核对其能否正确理解新事实与 generation，不能重新激活旧时间推断 writer。
- 容量/心跳不达标时不扩大 cohort；队列外告警失败单独挂账，不用手动 monitor.run 冒充自然调度恢复。
