# 英国赛事自动更新

2026-11-13 用户指定下一地区为英国，延续 P02 已确认规则。验收覆盖 2026 年 9—12 月英国 Group 1/2/3、Grade 1/2 与原 G3 对应的 Premier Handicap；实现不硬编码验收日期。

官方 BHA 目录确定年度赛事范围，近期官方公告修正改期、马场与停赛。TRA 现有付费账号提供出马表、历史卡表及完整赛果；合格完整的单一来源可以确认，不要求强制双源。BHA 结果站原 manual_browser_only 边界不变。

重点赛事（G1/同等级）确定资料出现后 5 分钟内更新，普通赛事 10 分钟。既有 T-30 预想隐藏、T+60 未确认赛果隐藏、改期重算、关键冲突隐藏和 7 天更正追踪规则继续适用。公开中文马名必须有可追溯 HKJC 来源，否则保留原名。

赛果包含所有实际参赛马及退赛、非完赛状态。API 的 non_runners 文本须与历史卡表按 horse_id 和规范化姓名核对，不得漏掉退赛马。原始马号被 NR 代替时不得按缺号推算。重量注明 lb；奖金区分总奖金与冠军奖金；赔率区分赛前平台报价与 SP。

本轮不包含其他地区扩围、QQ 或消息发送、旧全批数据包复活。合并、发布、数据写入及调度启用按根 AGENTS.md 的 G2/G3，以最终精确包为准。

赛前赔率使用 TRA 原始 bookmaker 报价：优先 Bet365，缺失时按报价方名称选首个有效报价；公开标注报价方与赛前性质，赛后改用明确 SP。原始多家报价保留在来源原件，不计算综合赔率；API 无时区的 updated 字面值仅保存，不冒充已核验 UTC 时刻。
