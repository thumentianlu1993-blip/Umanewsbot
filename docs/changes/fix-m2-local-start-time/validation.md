# M2 当地开赛时间缺失修复

## 根因与范围

2026-09-10 01:49 UTC 对生产候选 `69955960` 的只读核验确认：962/963 的
`race_datetime` 分别为 `14:00/14:35 UTC`，`timezone_name=Europe/London`，
但 `local_start_time` 均为空。来源 observation 23/24 提供完整 `off_time` 和时区，
没有独立的 `local_start_time`。字段审计 519/567 已记录正确候选 `15:00/15:35`，
却以 `runtime_admission_closed` 拒绝；来源合同和现有运行开关实际上均允许该字段。

原因是同步层只把来源直接提供的字段加入准入集合，漏掉已经算出的当地时间。
公开详情、日历、首页均读取存储的当地时间；调度和生命周期使用完整赛时，未因本缺陷丢失赛时。
页面沿用赛事当地时间口径：英国当地 15:00/15:35 对应北京时间 22:00/22:35。

本次只在已有准入集合中补入推导字段，要求同时满足：来源未单列当地时间、
`off_time` 已获准、来源合同允许当地时间、当地时间运行开关允许。
仍由原有时区转换、来源优先级、人工锁、schedule apply、claim 和事务逻辑处理。
不增加模板回退、迁移、配置、生产 SQL、抓取任务或新框架。
