# 赛事采集错误分类、失败原件与分类重试

用户要求先实现三项：错误分类、失败现场留存、按错误类型重试；保留现有身份及完整性校验。
当前分支为 `codex/race-gaps-20261122`，开发复用本会话独立 worktree。既有马会杯修复已发布；本变更是后续开发，生产尚未部署。

## 范围与验收

- 正式多来源 claim、赛前发现/刷新和多来源身份发现统一输出安全错误码及分类。
- 明确的未发布、资料不完整、锁/预算等待与采集故障分开计数；未知错误保守归为解析故障，不能猜测成官方尚未发布。
- 失败保留本次已获取的响应原件、内容摘要、解析器版本、首次/最近出现时间和重复次数；无响应、容量截断、存储不可用有明确标记。
- 同一内容和错误重复出现时延长解析重试间隔，产生内部 `needs_attention` 标志；不新增外部消息发送。
- 未通过身份、名单、状态、正式赛果和 claim 所有权校验的内容仍不可发布；本功能不产生任何豁免。
- 不变更公开地区、来源路由、配额、付费能力、自动化开关，不补采生产数据。

## 限制

原件仅限既有来源取得的响应体，不保存凭据、请求头、Cookie 或异常全文。不发起额外抓取。网络失败没有响应时只能留错误元数据。
失败留存有容量上限，不保证无限期审计；超过上限或原件已淘汰时可从元数据识别缺失，不能声称原件仍在。
