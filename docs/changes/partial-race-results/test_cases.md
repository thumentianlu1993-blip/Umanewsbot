# 验证

- 真实RED：冠军单行暂定公开且不确认；正式完整结果自动替换。
- 暂定含未知行、缺失前序名次、无冠军、并列：仅展示已有事实，不自动生成名次或完赛。
- 相同事实的暂定到正式升级、连续暂定更新、重复投递及正式后的迟到暂定。
- 身份不匹配、未知runner、手工锁、来源未准入、runtime关闭时不得公开。
- 单条与批量公开读取一致，缺审计/来源撤销仍拒绝；正式历史统计不纳入暂定。
- 多来源自然适配器仍返回result_incomplete以继续补采，不因公开暂定停止。
- PostgreSQL及按影响范围CI；独立只读review；禁止自动测试真实网络与生产依赖。

本机隔离PostgreSQL：初始核心用例真实RED（recorded而非projected），实现后96项回归通过。独立review发现跨来源runner ID比较与已知字段丢失两处P2；补最小反例后返修。精确最终树CI收据另行绑定，96项不作为最终交付收据。

两项review反例均得到真实RED，返修后98项PG回归通过。跨来源比较改为统一participant；按已公开字段检查缺失并保留旧快照。暂定未知状态不覆盖卡表已知状态。日历回归fixture补充日本地区，以符合既有五地区公开范围；未改变地区规则。

复审发现同一字段丢失问题的赔率/人气分支：两项真实RED后共用公开字段解析保护，法国两次自然claim式隔离回放验证保留赔率，日本用例验证保留人气。回退按是否已产生暂定投影分支，产生后仅冻结自动写入并前向修复，不能把旧writer作为兼容回退。

赔率/人气两项反例真实RED后，99项隔离PG回归通过（零跳过）。最终范围CI及同一reviewer复审绑定到后续精确提交，未生产部署。
