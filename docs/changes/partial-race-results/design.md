# 设计

沿用data_sync唯一写入者、claim锁与准入授权。结果规范化对暂定允许非连续名次；所有候选行仍须映射到既有本场runner，允许完整名单的子集，不为暂定创建名单。正式结果维持完整名单、terminal marker及现有身份校验。
暂定发布复用revision/publication/current指针与结果表；公开行仅包含明确结果，is_confirmed=false。暂定不改official_confirmed_at/result_confirmed_at/last_known_good，临场tracking保持provisional_result。
同源暂定更新按来源时间及仲裁推进；正式替换暂定属于成熟度升级，不要求correction开关。相同事实但phase升级不能被replayed吞掉。正式之后的暂定绝不降级。来源身份、手工锁、owner/lease及来源仲裁继续有效。
公开读取沿用单条/批量共用授权解析，暂定审计使用provisional_policy，正式仍使用official_route；暂定不要求已完赛和确认时间。页面通过既有赛果标题上下文显示暂定提示，模板结构不变；正式战绩继续过滤is_confirmed。
无模型变更。数据库事务内替换结果并切换指针；失败整体回滚；不在事务中进行网络请求。

实现前plan-eng-review检查：公开读的单条/批量复用函数可共同扩展；数据库唯一键已含phase，无需迁移。确认了三个必要边界并纳入实现：同hash跨phase需按phase查找revision、未知行不能伪造名次、正式升级不能被同事实replay吞掉。暂定新快照缺失已公开事实时保留旧快照并继续补采。符合来源授权的较新正式结果可替换暂定，不因来源优先级把暂定永久保留。
