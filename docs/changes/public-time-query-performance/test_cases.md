# 测试范围

1. PostgreSQL EXPLAIN ANALYZE：完整 instant/date/time 投影加日期过滤/排序，目录函数一次且只执行一次。旧实现必须失败，可捕获退回重复目录的 mutation。合成 80 场，限定单条查询 10 秒；不访问生产，不额外压测。
2. 时间语义：纽约/伦敦 DST 两侧及重复小时、跨北京日/年、秒精度、无效/空时区、当地日/钟冲突、非上海 date-only、上海 1992 边界、缺 UTC 的非上海钟。逐行比较旧/新 SQL 及 Python 合同（只对共享可识别时区），验证 PostgreSQL 特有合法名称仍接受。
3. ORM：count、exists、聚合、切片分页、union、相关 Subquery、空集合、重复编译及编译异常后上下文释放；参数化条件完整，下一条查询可见更新。捕获 CTE 丢失、参数漂移、跨请求结果缓存。
4. 既有首页/公开日历、默认日期窗口、周焦点、年份、分页、隐藏/重复赛事过滤回归；SQLite 冷连接兼容。选测工具确定具体范围，查询模块原高风险登记需要受审精确范围时据实报告，不偷偷降级。
5. 无迁移检查、工作流合同、diff 检查、独立只读 review。无任务/写入/新 schema，Celery 重试与数据库恢复测试不适用。部署后同入口限量只读结果/延迟与执行计划验证，失败回滚 web 镜像。
