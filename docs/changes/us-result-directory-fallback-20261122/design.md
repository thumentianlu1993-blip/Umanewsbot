2026-11-22 的进一步只读诊断确认：DRF 汇总目录最新仅到美国当地11月20日，
但月目录 `2611` 内11月21日的 BEL 第9场、CD 第10场、DMR 第8场正式 PDF 已经存在。

不能解决此次实际可用性缺口。误用年份 `2026` 子目录得到的200空体不是赛果证据。

固定原件在 `server/stable/fixtures/us_flat_results/directory_lag/`；provenance记录URL、
采样时间、原件与提取件SHA。PDF保留完整原件；HTML仅保留解析所需NEXT_DATA及JSON-LD。

## 实现

仅当DRF目录没有目标时，用既有 Sporting Life 当日终报页确定唯一比赛身份：
美国赛场、当地日期、赛事名称、等级、场次号和已有目标场次号须一致，比赛须WEIGHEDIN、
非隐藏且会议未取消。名称只沿用现有标点规整，并将尾部Stakes与S等价处理，不增加模糊别名。
存在同名重复、身份冲突或坏数据则拒绝，目录冲突不会触发回退。

根据独立终报身份构造同一DRF允许路径中的YYMM单场URL，不扫描目录或猜测多个场次。
PDF继续校验赛场、日期和场次号。Sporting Life详情还须匹配终报的ID、完整名称和计划UTC时刻；
复用同一当日快照，避免身份在两次读取之间漂移。
两份原件继续逐马核对完赛名次、马号、人员和退赛名单，缺失则不生成正式observation。
身份页SHA作为第三份来源保留到完整名单证明中。每次单场读取5份文档，受既有预算/白名单约束。
Native Diver详情UTC为11月22日，比赛当地日仍为11月21日，不能以URL日期替代当地日期。

不新增供应商、权限、额度、公开地区、人工马匹映射或付费调用；Colonial Cup的NSA正式卡表
与本次平地赛目录回退无关，继续作为独立待验证项。五场补时权威、已补两场法国名称、
英国有界收据实现及原监测服务保持。
