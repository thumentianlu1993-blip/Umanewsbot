### 直接可复核的问题

- 五篇选稿分别触发identity_evidence_mismatch（两篇）、subject_identity_unverified、
  editorial_schema、editorial_span_schema；模型的身份字段/证据位置不满足现有合同。
- 日本稿把中性的“氏”译成“先生”；フランス、イタリア、重賞等地域或通用术语没有中文化。
  不把无可靠中文名时保留人名/马名本身判错。
- 香港稿摘要将Frankie Lor和Lor并列成两个主体；正文把War Decree/ Harry Angel子嗣的表述
  写成“War Decree阉马”“Harry Angel阉马”，没有清楚保留血统关系；低负磅语境被直译成“没有负重”。
- 英国稿正文首段人马主语错接，摘要新增William Haggas也作了评价；
  “a length-and-a-half → 1.5个马位”被数字校验误判，改成“一个半马位”后才通过。
- 美国稿“Nov. 27 → 11月27日”被数字校验把11识别为新增数字，唯一一次局部修复未解除。
- 日本、法国诊断均获模型自审pass，但日本稿仍被逐段复核判为不合格，证明不能只依赖自审全true。

实体与既有AI辅助参考的逐次位置一致性：174匹配、36额外、26缺失，严格F1约0.8488；
仅1/5整篇完全一致。该参考包含部分用户裁决，整体不是人工标准答案；这些数字是参考一致性，
