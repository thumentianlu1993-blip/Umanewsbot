首批可用地区的开发估算：D01–D05 共 8–13 人日，加一地区 D06 与 D07 为 **10–18 人日**；D08 另计 1–2 人日及真实赛期。其余八地区约 **8–24 人日**，另加观察/修复；全项目约 **19–44 人日**（含一次 D08，特殊来源限制或大 parser 缺口另列，不隐性吞掉）。按 1 人日约 8 工程小时，等待授权、套餐、赛期不算投入。

本估算不绑定日历日期：开始实施后 D01 完成即报告首区、剩余人日和基于实际开工日的预计日期。候选优先从已有 adapter/授权/完整样本/近期赛日齐全的地区选，条件相近先复用度高者；不规定必须日港，也不等待九地区全部可用。地区不能达到 SLA 时明确缺口，不能偷改标准。
