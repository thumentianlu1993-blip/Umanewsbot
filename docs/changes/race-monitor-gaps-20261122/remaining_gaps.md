## 英国代码修复

根因在赛果写入路径：它可以补基础资料，却不投影已解析的时间；缺少赛前正式卡、直接进入赛果补采时暴露此缺口。

在首次正式投影和同值赛果重放分支补齐缺失时间。补写必须通过当前 `race_time` 选源准入，且时间来源与赛果来源身份一致；检查字段开关、来源观测时间、当地日期及字段/基础资料人工锁。两项已有时间只要有一项冲突，整组不补；已有值不覆盖。每个补值保留 observation、来源 URL、摘要、字段权威和审计。

本次不是实际开跑时间校准；TRA 原件中的 off_time 按现有赛事时间合同使用。结果 claim 不因这次填空重置调度或重新发布既有赛果。
