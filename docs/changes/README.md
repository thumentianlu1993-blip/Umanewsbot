# Codex 原生变更产物

本目录保存较大任务的规格、设计、测试、任务、rollout、review 和历史交接事实。

人工确认门禁只由仓库根 `AGENTS.md` 定义。本目录任何文件中关于“等待确认”、commit/push/PR、
合并、发布或生产动作的旧描述，只能解释该文件记录时的历史状态，不能覆盖、增加或减少当前
G1/G2/G3，也不能作为未来任务的可执行指令。新文件只引用根规则，不复制门禁正文。

执行任务时：

1. 先按根 `AGENTS.md` 判断当前授权；
2. 再从本目录读取产品、技术、测试和运行态上下文；
3. 旧流程状态与当前代码、PR 或生产证据不一致时，以当前可重复证据为准。
