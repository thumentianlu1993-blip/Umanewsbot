# 实施前测试矩阵

本文件是待实现用例，不是已通过测试报告。纯文档阶段只校验链接、格式与合成示例的跨度。

| ID | 测试对象 | 输入/变异 | 预期及能捕获的错误 |
| --- | --- | --- | --- |
| A01 | Unicode跨度 | emoji/组合字符/全半角，按UTF-16偏移 | 拒绝错误切片；不允许字符规范化掩盖 |
| A02 | 多次提及 | 标题Alpha＋正文两次Alpha，只给一处 | TP1/FN2，整篇失败；捕获按名称去重 |
| A03 | 边界变体 | 同一mention两个允许跨度同时预测 | 一对一最多1TP；若协议重叠阻断则主失败 |
| A04 | 类型 | 正确位置horse改为person | FP1/FN1＋type_error，不算部分正确 |
| A05 | 机构嵌套 | 晨光牧场抽晨光horse | 边界/类型错，不能把内部子串算命中 |
| A06 | 普通词 | 普通“最后一战”与明确名为“最后一战”的赛马 | 前者omit/common_word皆可，后者必须horse；禁止字符串黑名单 |
| A07 | 不确定 | 原文孤立晨光，无类别依据；另构造schema错误review | 都不自动通过；schema错误只计安全拦截，不计有依据的不确定识别 |
| A08 | 人工gold | AI预标自填human或未裁决 | 拒绝gold冻结，合成示例不能冲真实数量 |
| A09 | Context | 引用不含mention或被改写 | lint失败；重复context但偏移明确可接受 |
| A10 | 正负例 | 同跨度既必须horse又hard_negative | lint失败；contained_generic允许位于明确允许的全称变体内部 |
| D01 | 分组泄漏 | 同事件不同URL/转载跨dev/holdout | split无效，不能只靠URL不同通过 |
| D02 | 派生泄漏 | 锁定文改写成开发few-shot | leakage_group交叉即拒绝 |
| D03 | 曝光 | 已调试旧3篇/20篇放holdout | 无效，迁回开放回归而不伪称独立 |
| D04 | 数量覆盖 | 100/100但某区缺样本，复制补齐 | 报缺口和重复，不能认作完整五区基准 |
| D05 | 长文容量 | gold>128实体/业务payload过大 | 不截gold；报告capacity与自动失败 |
| D06 | 标注变化 | 看候选输出后补允许变体 | 冻结SHA变化，版本失配；需成对重算且不恢复独立性 |
| D07 | 数据隔离 | 运行输入包含gold或expected_action | 封包检查拒绝；开发进程不能读取锁定目录 |
| E01 | 空集合 | 零gold、零预测且协议有效 | 整篇通过，P/R分母0为N/A；全数据汇总不崩溃 |
| E02 | schema失败 | 实体文本正确但多字段decisions | 正式主失败，不自动删字段；诊断独立保存 |
| E03 | 定位失败 | 原文引用两次，默认第一次 | 不得补出预测；正式失败 |
| E04 | 修复 | 首轮失败、一次修复成功 | 首轮0/最终1，费用含两次；重复结果重放不重复记账 |
| E05 | 截断/unknown | length/usage缺失/远端无收据 | 非通过、保留预约；unknown停活动且禁止重发 |
| E06 | 未完成 | 固定100只执行20、成功18 | 报18/100观察下界及未完成，18/20仅辅助覆盖 |
| E07 | 退化 | 旧60通过，新修好30弄坏5 | 新85、净+25，输出5退化，不仅报修好30 |
| E08 | 重复试验 | 三轮70/85/90，每篇取最好 | 拒绝best-of冒充单次；三轮分母均100 |
| E09 | 重评分 | gold纠错后只改candidate | 拒绝不对称比较，旧报告不可覆盖 |
| E10 | 可复现 | 同回执离线评分两次、顺序不同 | 计数/匹配一致；代码及输入SHA一致 |
| E11 | 漏读Gold | 评分器能访问API、执行器挂载gold | 拒绝隔离检查；不存在隐式gold提示 |
| E12 | 并发恢复 | 两执行器同一operation | 至多一方获发送权；崩溃不把unknown当未发送 |

评分器先用上述已知答案取得RED/GREEN，再运行真实回执。真实准确率不由合成用例通过推导；基准的人工标注一致性与系统测试分别报告。
