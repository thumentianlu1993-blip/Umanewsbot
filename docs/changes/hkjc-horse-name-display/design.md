# 实现设计

新增集中名称策略，按 notes 的完整 key=value 解析来源、官方层级、复核状态和 evidence URL hostname；重复键、伪造域名、待复核、缺少官方证据均拒绝。source 仅 hkjc/hkjc_overseas，证据域为 hkjc.com/hkjc.com.hk 及其子域。若有 original_zh_hant，各候选须经原导入 OpenCC 简化后与当前 target_zh 一致；缺少该字段不直接拒绝，因为原导入仅在繁简不同才记录。来源标记自身不能证明页面内容仍存在，因此对证据缺失的旧记录采取隐藏，不自动补证。

使用默认关闭的 HORSE_NAMES_REQUIRE_HKJC_ENABLED，发布包明确启用；关闭恢复原展示。不改变后台 display_name、has_translation 和数据库字段。新增有效译名属性供翻译使用，公开 profile 属性忽略人工 display_name_zh 覆盖。血统优先关联 term，再关联 profile 的 primary term；无法证明的纯中文文本隐藏，日文/拉丁原名保留。

历史已发布新闻扫描单独只读命令：按隐藏术语目标和中文别名检索标题、摘要、正文，报告潜在影响字段和术语 ID。命中仅是文本关联候选，不是实体身份确认；不执行替换。


## 交叉路径约束

- 赛事原字段本身为中文时，以现有正式译名精确查找原实体；证据不合格则回退该实体原名，多解或找不到可信原名时显示“名称待核实”。旧赛事展示在开关启用时也走统一马名解析；骑师仍走原逻辑。
- 发布一致性与后续稿件校验使用有效译名，不能要求模型恢复已禁止的中文名。历史修复的快照摘要同时绑定来源 notes、翻译状态和开关，避免旧 manifest 跨策略误用；本任务不执行历史修复。
- 新闻价值评分继续使用已识别实体是否原有译名这一事实，公开名称资格不删除既有马匹命中。英文普通词/不确定候选不因其存在同名马匹而强制保护。
- 繁简转换沿用原导入的 OpenCC t2s，并复用转换器；来源判定缓存有界，键包含目标译名和 notes，改名/改来源会失效。

- 英文同名实体原先依赖存储译名差异判断冲突；该依据与公开目标值分离，避免隐藏译名后把多解误当成两个有效评分命中。
- 历史影响报告按名称而非按实体跳过：官方正式目标可以排除，但同实体下未核验的中文别名仍列入候选。
