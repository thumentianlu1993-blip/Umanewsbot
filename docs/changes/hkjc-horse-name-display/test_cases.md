# 测试范围

1. hkjc/hkjc_overseas 官方证据、繁简一致、无 original 字段的原简体名允许。
2. manual/community、恶意 URL、重复 source、requires_review=true、原文与当前译名不一致拒绝。
3. strict/legacy 赛事名单与赛果一致；骑师保持原译名。
4. 档案公开名称不使用人工覆盖，后台字段保留；血统无可信中文隐藏，原文保留。
5. 日文与英文实体决策、术语替换及模型占位符保护，不让未采用的中文译名进入术语表。
6. 默认关闭恢复旧行为；历史扫描只读且输出潜在命中范围。
7. 使用本地固定镜像、network none、内存 SQLite，无真实服务调用。

8. 开启术语一致性 enforce 后，保留原名的译文可以标记 publish-ready；禁止译名及其未核验中文别名不被输出校验认可。
9. 开关前后同一已识别马匹的新闻评分命中、优先级不变；普通英文词仍不强制保留。
10. 已存中文的赛事原字段，两路径均须验证；官方中文保留、人工中文回原名、未知/多解显示名称待核实。
11. 来源/状态/开关变化使旧一致性修复快照失效，避免历史 manifest 跨策略使用。
