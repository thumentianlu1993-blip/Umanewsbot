# 实现设计

赛季目录从官方 Pattern Book 提取，以调用参数筛选日期。HKJC 单场来源使用赛日和马场入口发现实际场次，
不持有 2026 年或目标 event ID 白名单。全日赛果页只用于发现，完整结果必须读取单场页，且与逐马竞赛事件表核对集合。
报名入口按正式卡表、本地报名、受审国际赛活动站点的顺序发现；所有详情均核对日期、名称、马场及总数。

赛前调用已有 `race_pre_race` 的行锁、租约和调度，并写 `RaceEventDataCandidate`；不直接创建正式 runner。
来源为 `hkjc_pre_race_v1`，公开预览尊重字段开关、人工锁、owner、baseline 和 handoff。
候选阶段只前进；未编号报名不能授予来源身份或由后台通用 apply 写为正式名单。正式卡才进入既有身份匹配链。
报名人数上限在 HKJC 调用中单独放宽，其他来源和正式卡保留既有限制。

默认关闭 `RACE_DATA_SYNC_HKJC_PRE_RACE_ENABLED`，启用后的观察窗口参数默认 45 天，上限 60 天；关闭时保留既有四天窗口；不新增迁移、任务队列或独立调度器。
验收命令 `verify_hkjc_sources` 不访问业务数据库，显式 `--allow-network` 时读取官方白名单页面，保存 URL、原文 SHA 和结果；
不传该参数时仅重放同目录缓存。PDF/网页原文及 CSV 存专属 runtime，不提交大体积原件。
