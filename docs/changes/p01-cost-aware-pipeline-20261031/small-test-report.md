## 对照阅读发现与处理

22726的实体模型把非马名片段“ラストラ”标成horse。该片段位于原文断开的“ラストラ ン”中，位置虽真实唯一，语义类型却错误，导致保护后译文出现“ラストラ 战”。全文审校仍返回pass、九类checks全true，说明**确定性定位不能验证实体类型，模型自审也不能替代内容验收**。未猜测中文译名、未把原文修改成可通过形式，也未放宽上下文校验。

同篇包含“屈腱炎”“けが”和“ラストラン”，原风险词未识别，因此使用base审校。已在最终候选补齐这些日文词及空白变体，发布检查沿同一函数重验，只提高deep要求；离线确认该样本应走deep。但没有新的deep响应，不能宣称误放行已经被模型修复。

22725返回的实体“天皇賞・秋”搭配上下文“秋の天皇賞が2000メートル戦になって以降”，实体字面并不在该上下文中；拒绝是正确的。7611为第一次France Galop返回的上下文包含该名称两次，不能猜选择哪个，拒绝同样正确。初版没有新增实体澄清重试，失败转待审符合已批准方案。

事件身份仍使用既有证据契约；22726身份跨度不符，另两篇被选稿模型拒绝。此次没有扩大范围修改事件身份规则，报告保留事件失败与诊断翻译的区别。
