# 测试用例与验证顺序

方案2026-10-31复审通过后编写；所有自动化使用隔离数据库/无网络、合成或冻结输入，不调用生产服务。小测独立执行。

| 编号 | 行为与正例 | 必须拒绝的反例/失效场景 |
| --- | --- | --- |
| C01 | Unicode、标题边缘实体、同名不同上下文定位并保护恢复 | 缺上下文、空上下文、重复歧义、大小写/Unicode猜测、重叠、旧跨度旁路、超128 |
| C02 | 九类全文审校；摘要/跨块/人工body两端引用；遗漏整块修复 | 伪造/歧义引用、空引用伪跨度、pass带问题、fail无证据、旧span契约 |
| C03 | 数字日期硬检查先执行，准确标记正文或摘要 | 错数字/单位、缺块、重复块、占位遗漏不得消耗普通审校后直接通过 |
| C04 | 精确局部替换及protected raw SHA绑定；非目标逐字不变 | 越界/重复/缺失patch ID、旧基线、中文名逆向猜token；第二次修复 |
| C05 | 初次结构失败可一次full repair，最终全文审校 | 无法安全解析或人工稿自动改写；修复后绕过hard check |
| C06 | base非思考、deep思考均strong；风险稿和uncertain升级 | 降级模型、伪profile、无证据uncertain循环、升级后修复回落base |
| C07 | SDK单次调用、显式thinking、token额度和lease匹配 | finish_reason非stop/工具输出/usage未知、发送后重发、未经预留调用 |
| C08 | 同文章同输入body/entity paid成功缓存派生 | 跨文章/语言/策略/模型/输入、unknown/未结算/派生链、原回执篡改；旧审校复用 |
| C09 | 不同正文审查回执ID使用同一稳定投影 | 内容变化被投影抹除；缓存隐藏原付费、全局unknown被绕过 |
| C10 | PG单篇并发锁，所有run历史实际+在途+unknown守恒 | 跨revision/跨日月/币种改动重置单篇；两worker超额；业务锁与金融锁倒序 |
| C11 | v2同账期切策略保留费用；迟到原账结算 | 清零账、重新建空账、旧worker回写cap；降cap清除unknown/overage |
| C12 | 发布重放实体、原始翻译与补丁、最终全文强审校 | target/上下文/原paid缓存/patch范围/profile篡改、旧契约冒充v2、缺最终audit |
| C13 | legacy未启用行为和数字日期回归 | 默认启用v2、QQ/旧稿变化、人工输入丢失 |
| C14 | 三篇缓存小测双预算、每篇增量0.15、总增量0.50 | 新unknown不停止、旧unknown不计历史、扩大样本或重发旧请求 |

先在现有测试模块写最小真实RED；再实现对应纯函数、金融及状态机路径，取得GREEN。新增边界在受影响模块补充。固定提交通过影响计划要求的隔离PG回归与独立只读review后才冻结小测包。报告区分离线断言、模型审校、人工抽查、事件有效性和发布资格。
