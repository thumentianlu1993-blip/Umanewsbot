# P01低成本内容流水线产品规格

## 状态与依据

2026-10-31，用户批准按已讨论方案实现，并要求严格依次完成：产品spec → 技术方案 → 独立复审至通过 → 测试用例 → 实现 → 独立代码review至通过 → 少量文章实测。用户补充：每个实体的原文上下文为必需项。

本文承接P01既有全文、选稿、独立新增稿件和质量要求。当前业务基线为1975e223：数字/日期修复已完成，尚未部署；上一轮全Pro思考测试暂停在1篇完整、第二篇翻译响应已恢复。本任务仅在本线程分支实现和隔离验证，通用人工确认引用根AGENTS。

## 目标

降低思考token、手工字符计数和整篇反复翻译产生的成本及耗时。每篇入选稿继续经过强模型专名识别和独立全文审校，强模型能力与思考模式分别配置。普通短中篇以0.02–0.05美元/合格稿为优化目标，不作为未经验证的费用承诺；长篇单列。

## 产品要求

P01 正文来源、许可、可信时间、地域、清洗和广告/付费墙检查保持原有边界；疑似模板仅审查疑似块及必要上下文，不能因省费删除真实正文。

P02 每次实体出现必须附原文名称、类型、区块ID、原文上下文。上下文逐字引用、非空、包含本次名称，程序必须能够唯一确定对应原文位置；同名多次出现分别提供上下文。找不到、重复歧义、冲突或上下文不足时待审，不模糊匹配、不猜跨度、不补写原文。上下文可为完整短块；不强制固定左右字数而拒绝标题或段落边缘实体。

P03 模型判断实体语义，代码完成字符定位、重复/重叠检查、占位符保护和恢复。仍需完整实体覆盖声明及全文审校，词库命中不构成完整性证明。可信中文名才替换；未知保留原名；识别不等于跨模块身份关联。

P04 默认采用强模型非思考实体识别和全文审校；首轮小测翻译也采用Pro非思考，以分离模型更换与思考模式的影响。输出额度按阶段配置，翻译可依长度在已配置硬上限内调整。禁止截断响应当成功；能力不足不能以便宜模型未经完整审校发布。

P05 先执行结构、原文区块、占位符、数字/日期有限格式检查。明确的结构或数字问题生成可定位问题，不先消耗全文审校；需要语义判断的比例、归属、否定和金额单位不能仅靠数字表面判断通过。数字日期沿用已验证模块。

P06 每篇最终全文都须经强模型审校，覆盖标题、摘要、所有正文块及引语，检查专名、数字单位、日期名次、否定、计划/发生、归属、遗漏和新增。模型不得输出自行打分替代证据。失败/不确定须附可核实引用；引用定位由代码完成，缺省或歧义按不确定处理。

P07 风险分级只决定是否增加深度思考，不能取消普通稿全文审校。退役、重大伤病、禁赛、赛果更正、实质更正稿和已识别复杂关系应升级；常规审校uncertain可最多升级一次。预算不够则待审，不降级自动通过。缺少年份/身份依据仍按原规则待审，不以深度思考猜全。

P08 最多一轮针对性翻译修复。问题可定位至明确区块时只返回替换块；程序合并并证明其他块未变，再检查整个稿件并重新全文审校。摘要和标题被修改也必须复审。问题涉及广泛遗漏/全文结构时才允许明确记录理由的整篇修复。无法安全构建修复任务或修复后仍失败转待审；人工稿不得自动改写。

P09 已完成结果复用必须绑定内容、来源、语言、模型、模式、提示词和规则版本。初版跨revision仅复用同文章、同来源内容的正文审查/实体识别结果，保留派生回执和原始回执；术语替换重新核验。事件候选/已发布事实变化要重判；译文变化后旧全文审校不得复用。unknown、未完成或证据失配不得缓存命中。

P10 预算区分实际用量费用估算、在途预留、unknown预留，显示单篇、当日、当月/整批口径。失败、修复、升级均计费，重试不产生新免费额度；同文章重新建revision不能绕过单篇费用限制。所有网络调用之前原子预留，无法确定是否计费则保留预留并停止，不重发。

P11 原文/译文/规则版本变化使相关回执失效；网页发布仍重验强模型回执、实体定位、全文目标、事件身份及预算状态。新v2契约显式启用；旧契约回执不能跨版本作为新上下文要求的证明。生产模式保持关闭，既有稿件与QQ链路不改。

## 验收与边界

- 每实体上下文必填；Unicode、重复名、边缘实体、重叠与歧义反例均可验证且不得猜测通过。
- 普通和高风险稿都具有最终全文强审校证据；思考升级有可追溯原因、次数和费用。
- 局部修复不改非目标块；最终全文重新审校；原始数字日期防误拦截及负例保持通过。
- 缓存不复用过期、unknown、跨文章、错策略/模型的回执，不隐藏原始费用；单篇并发预约、跨revision和unknown均守恒。
- 小测报告区分事件有效性、翻译审校、人工抽查与发布资格，并记录P50/P95（小样本明确局限）、候选/合格分母费用、token、模式、修复/升级次数、拒绝原因。人工gold和生产验收不由小测替代。
