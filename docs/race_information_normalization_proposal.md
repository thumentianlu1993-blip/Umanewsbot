# 赛事信息归一化规则（评审草案）

日期：2026-09-18。状态：用户已认可归一化规则，代码实现方案v2已获独立子 agent 复审APPROVED；尚未实施、清洗数据或部署。

代码方案见 [PLAN.md](changes/normalize-race-information/PLAN.md)，审阅过程见 [REVIEW.md](changes/normalize-race-information/REVIEW.md)。代码方案基于固定主线快照补充了已有归一化服务、字段及实时赛果入口；下文最初的本地核对不代表主线缺少这些能力。

## 范围与依据

适用于赛事日历、详情、出马表、赛果、历年冠军，以及马匹页内引用的赛事信息。新闻中的结构化赛事卡片复用相同规则；正文术语需要上下文，不能全篇机械替换。

已核对本地模型、等级解析器与赛事详情模板：等级徽章使用 `normalized_grade` 或原文回退，基础资料使用 `grade_text`；距离直接使用 `distance_text`；出马表与赛果分别出现“热门”和“人气”。以上为本地代码事实，未核查生产分布或影响数量。

已有术语决策要求按正式概念与多语言别名解析，并保留来源原文。本草案延续这一原则；历史导出数量及旧生产状态不作为本次依据。

## 用户已明确的要求

1. 大小写统一。
2. 同一单词在相同含义和语境下尽可能使用同一译法。
3. 距离仅展示中文单位“米”“英里”“英尺”；英制后附对应公制。不得直接展示 m、メートル、ft 等来源写法。
4. 等级只展示标准形式，例如 G1、G2、G3、Jpn1；不得展示 Grade1、GI 或“重赏 G1”等混合说明。

## 建议规则清单

下列规则已经用户认可；具体解析、歧义处理、兼容和回滚合同见实现方案。无来源支撑的字段保留缺口，不能为统一格式猜填数据。

| 项目 | 建议规则与示例 | 保留的区别 |
| --- | --- | --- |
| 大小写 | 缩写用 JRA、NAR；等级用 G1、Jpn1；英文专名采用正式词库写法 | 不机械首字母大写；保留正式名称内部大小写、重音和撇号 |
| 中文与译名 | 默认简体中文；赛事、马匹、骑师、练马师、马场统一使用正式词库译名 | 同词不同义、同名不同实体不能合并；未命中保留原名并标记待补 |
| 赛事名称 | 标准中文名称为主；年份、届次、等级分别展示 | 保留年度冠名、历史更名和别名证据；不能仅凭名称近似合并赛事系列 |
| 通用赛事词 | 为 Stakes、Cup、Trophy 等建立语境化译法表；整条已确认赛名优先于拆词翻译 | 不覆盖已有正式中文专名 |
| 等级 | Grade 1、Group 1、GI、GⅠ → G1；JpnⅠ → Jpn1；J・GⅠ → J-G1；Listed → L；Open → OP | 保留 G、Jpn、J-G 区别；按当年等级。地方等级保留经核实的自身代码 |
| 等级与条件 | “重赏 G1”在等级栏仅显示 G1；新马、未胜利、1胜级等放类别／条件 | 无法识别显示“待核实”，确定无分级显示“无分级”，两者不同 |
| 公制距离 | 1600m、１６００メートル、1.6公里 → 1600米 | 原单位必须明确，不按常见赛程擅自取整 |
| 英制距离 | 1 mile → 1英里（约1609米）；1m 2f → 1.25英里（约2012米），后者须来源明确 m 为英里、f 为弗隆 | ft 是英尺，f／fur 是弗隆，yd 是码；按用户单位范围换算为英里／英尺或米，含义不明的 m 不自动换算 |
| 距离精度 | 精确换算保留；公制附注四舍五入至整米；复杂组合可显示“1英里330英尺（约1710米）” | 来源本身“约”的限定保留；官方名义距离与换算值不一致时须保留差异 |
| 场地与赛种 | 芝／Turf → 草地；ダート／Dirt → 泥地；Synthetic → 复合赛道；平地／障碍单列 | 材质与赛种是不同维度；All Weather 等按来源确认后映射 |
| 跑道方向与布局 | 左回り → 左转；右回り → 右转；内回り → 内圈；外回り → 外圈 | 直道、方向、内外圈分项，不能挤入距离字段 |
| 场地状况与天气 | 天气用固定中文词；场地状况按国家／机构建立映射 | 不把不同体系的 Good、良、Soft、稍重强行等同；数值等级、复合描述保留 |
| 地区与马场 | 使用受控地区名、标准马场名和别名表 | 同名马场不合并，临时改场以实际举办地为准 |
| 日期时间 | YYYY-MM-DD；24小时制 HH:mm，明确当地时间；可同时列北京时间 | 只有日期不补00:00；按当地时区和赛事日期处理夏令时、跨日 |
| 年龄性别 | 3yo+ → 3岁及以上；牝 → 雌马；牡 → 雄马；騸／セン → 阉马 | 仅限雌马与性别不限不同；历史年龄按当年来源 |
| 条件与负重制度 | 按年龄、性别、资格、负重制度分项，使用审核后的统一中文词表 | 让磅、定量、别定等制度不合并 |
| 负重 | 建议列名“负重”；57kg → 57千克；英制可显示“126磅（约57.2千克）” | 与马体重分开；减磅、超重说明独立保留，无单位数值不猜单位 |
| 编号 | 纯数字全角转半角；马号、闸位、枠番分列；保留合法马号1A | 不按展示顺序猜缺失编号 |
| 名次与状态 | 阿拉伯数字名次；并列显示“并列第1”；退赛、未完赛、取消资格分别表示 | 不填0名或猜最后一名；正式名次与展示排序分开 |
| 完赛时间 | 来源格式明确时，1:32.5 → 1分32.5秒 | 保留原精度，不补零制造精确度；与开赛、分段时间分开 |
| 差距 | nose → 鼻差；head → 头差；neck → 颈差；1½ lengths → 1.5马身 | 明确相对前一名还是冠军；马身不换算成固定米数 |
| 赔率与排名 | 标签建议“赔率／热门排名”；赔率标明制式；“3番人気” → 第3热门 | 制式明确后才换算；5/2的十进制赔率为3.5；保留更新时点、赛前／最终状态 |
| 奖金 | 金额＋明确币种，如100万美元；总奖金与冠军奖金分列 | 不保留含义不明的 $／¥，不自动换成人民币，口径未知待核实 |
| 数字标点 | 数字半角、小数点统一、中文附注全角括号，清理多余空白和网页转义残留 | 按来源解析逗号是千位符还是小数点；保留专名字符与URL |
| 空值与状态 | 空单元格“—”；未确定“待定”；来源未公布“未公布”；冲突“待核实” | 缺失不填0；已结束不等于赛果已确认；业务状态与数据质量分开 |

## 落地与验收建议

- 保留原始值、原单位、来源URL、获取时间；标准展示值可追溯。统一规则覆盖日历、详情、出马表、赛果和历史引用。
- 先形成差异预览，区分确定性格式修正、术语命中、单位歧义和身份冲突；待核实值不猜填。
- 后续实现需验证罗马数字等级边界（JpnII、J・GIII不得误识别成一级）、模糊 m、英制组合、跨日时区、并列名次、赔率制式，以及重复归一化结果不变。
- 当前交付为已认可规则与实现方案／审阅，没有执行业务代码修改、批量翻译、抓取、导入或部署；影响记录数未知。
