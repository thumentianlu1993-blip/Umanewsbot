# 外部马名索引识别规格

## Purpose
使用本地外部赛马数据索引辅助识别新闻中的日文马名，区分“已有中文译名的正式术语”和“确认是马名但尚无中文译名的外部索引命中”，降低真实马名漏报和普通词误报。

## Requirements
### Requirement: 使用本地外部马名索引识别文章马名
系统 SHALL 使用本地 `ExternalHorseAlias` 索引识别文章日文标题和正文中的已知外部马名。识别必须只访问本地数据库，不得在新闻准备、翻译、校验或候选发现同步链路中实时请求外部站点。

#### Scenario: 外部索引命中真实马名
- **WHEN** 文章标题或正文包含 `ExternalHorseAlias.normalized_name` 可匹配的日文马名
- **THEN** 系统在结构化识别结果中返回该马名、外部 horse ID 列表、索引来源、置信度和原文命中文本

#### Scenario: 外部索引未命中普通片假名词
- **WHEN** 文章标题或正文包含未命中 `ExternalHorseAlias` 且被普通词过滤表覆盖的片假名词
- **THEN** 系统不得把该词作为外部已知马名返回

#### Scenario: 新闻处理不得发起外部请求
- **WHEN** 系统为文章执行马名识别
- **THEN** 系统只查询本地 `TermEntry`、`ExternalHorseAlias` 和必要配置，不调用 netkeiba、keibascraper 或其他外部网络接口

### Requirement: 区分正式术语、外部已知马名和启发式疑似马名
系统 SHALL 为文章马名识别结果标记来源类型。正式马名术语表示已有中文译名，外部已知马名表示本地索引确认是马名但未必有中文译名，启发式疑似马名表示仅由规则推断。

#### Scenario: 正式术语优先
- **WHEN** 同一日文文本同时命中启用的 `TermEntry(term_type=horse)` 和 `ExternalHorseAlias`
- **THEN** 系统将该文本作为正式术语命中处理，并不得把它列入需要原样保留的外部未知马名

#### Scenario: 外部已知但无中文译名
- **WHEN** 日文马名命中 `ExternalHorseAlias` 但未命中启用的正式马名术语
- **THEN** 系统将该文本标记为外部已知马名，保留所有匹配的外部 horse ID，并标记需要在译文中原样保留

#### Scenario: 仅启发式命中的马名
- **WHEN** 片假名候选未命中正式马名术语、未命中外部马名索引且通过启发式马名打分
- **THEN** 系统将该文本标记为启发式疑似马名，并保留对应置信度或识别理由

### Requirement: 马名识别必须可批量查询并保持确定性排序
系统 SHALL 对文章中提取到的候选马名做标准化后批量查询外部马名索引，并对结果进行确定性去重和排序。结果排序必须优先保持文章出现顺序，同一位置存在重叠命中时优先保留更长文本。

#### Scenario: 批量查询候选 token
- **WHEN** 一篇文章包含多个片假名候选 token
- **THEN** 系统使用标准化候选集合批量查询 `ExternalHorseAlias`，而不是逐词扫描全部外部索引

#### Scenario: 重复出现同一马名
- **WHEN** 同一外部马名在标题和正文中多次出现
- **THEN** 系统只返回一个去重后的识别项，并保留足够信息说明其命中文本和来源

#### Scenario: 长短文本重叠
- **WHEN** 同一位置存在长短重叠的马名候选
- **THEN** 系统优先保留更长的外部马名命中，避免短 token 截断完整马名

#### Scenario: 同名马对应多个外部 horse ID
- **WHEN** 同一标准化日文马名在 `ExternalHorseAlias` 中对应多个外部 horse ID
- **THEN** 系统在同一个识别结果中保留全部匹配外部 horse ID，并使用确定性排序选择展示用主 ID

### Requirement: 普通词与外部马名冲突必须使用强上下文消歧
系统 SHALL 在片假名文本同时命中普通词过滤表和 `ExternalHorseAlias` 时执行上下文消歧。只有文本处于强马名上下文时，系统才能将其作为外部已知马名；否则不得把该普通词作为马名识别结果返回。

#### Scenario: 普通语境中的同名词
- **WHEN** 文章包含同时命中普通词过滤表和 `ExternalHorseAlias` 的 `タイトル`，且上下文为 `記事のタイトル`
- **THEN** 系统不得将该 `タイトル` 作为外部已知马名返回

#### Scenario: 强马名语境中的同名词
- **WHEN** 文章包含同时命中普通词过滤表和 `ExternalHorseAlias` 的 `タイトル`，且上下文为出走、赛果、骑手、父母、产驹、性龄或标题主语等强马名语境
- **THEN** 系统可以将该 `タイトル` 作为外部已知马名返回，并在识别结果中标记普通词冲突
