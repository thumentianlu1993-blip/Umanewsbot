## Why

当前未知马名识别主要依赖片假名规则，容易把普通词误判为马名，也会漏掉真实马名，进而导致翻译和自动化校验被错误拦截。为了后续优化马名定位，需要先建立可查询、可审计、可增量维护的本地赛马数据缓存。

## What Changes

- 新增基于 `keibascraper` / netkeiba 数据源的近两年赛马数据导入能力。
- 新增本地外部赛马数据表，保存抓取到的比赛、出走表、赛果、马匹血统和马匹出走履历字段，避免只保留马名而丢失后续可用信息。
- 新增可恢复、可限速、可审计的导入任务和管理命令，默认严格控制请求间隔与批量规模。
- 新增导入运行记录、失败记录和幂等去重规则，支持中断后继续导入。
- 新增配置项控制导入开关、回溯年限、请求间隔、单批上限和是否允许外部请求。
- 不在本 change 中直接改变自动发布、AI 改写或未知马名校验策略；后续 change 再让自动化链路消费本地马名索引。

## Capabilities

### New Capabilities
- `external-horse-data-import`: 从受控外部来源低速导入并维护本地赛马数据缓存，覆盖近两年 netkeiba 比赛、出走、赛果、马匹和履历数据。

### Modified Capabilities
- 无

## Impact

- 代码范围：
  - `server/stable/models.py` 与迁移：新增外部比赛、出走、赛果、马匹、履历和导入运行记录模型。
  - `server/stable/services/`：新增外部赛马数据导入、限速、幂等 upsert 和错误记录服务。
  - `server/stable/tasks.py`：新增 Celery 导入任务，但默认不自动全量运行。
  - `server/stable/management/commands/`：新增近两年导入、单月导入、单场/单马补抓和 dry-run 命令。
  - `server/app/settings.py` 与 `.env.example`：新增导入配置。
  - `docs/`：新增或更新运维说明、运行手册和当前状态。
- 外部依赖：
  - 固定引入 `keibascraper` 版本并更新部署依赖；如依赖过重或运行不稳定，应通过适配层隔离。
- 生产影响：
  - 导入任务会访问 netkeiba，必须默认关闭自动调度，人工明确执行。
  - 生产执行必须限速、分批、可暂停，并优先在低峰时段运行；同一数据源同一时间只允许一个导入运行发起外部请求。
  - 导入失败不得影响新闻抓取、翻译、自动化发布和公开前台。
