## 2. 产驹格式矩阵

- 已知母马 + 已知父马：使用两者中文目标。
- 未知母马或父马：逐字保留对应组件，不音译、不意译、不拆分。
- 无括号：只规范 lot 名。
- `(牡)` 位于引号内：移动为中文引号后的 `（公马）`。
- `(牡、イクイノックス)` 位于引号后：输出 `（公马，父春秋分）`。
- `(牡、父イクイノックス)`：不得产生“父父春秋分”。
- 同段多个 lot：每个 placeholder 唯一且按字段/位置确定性编号。
- 未知母马内部含文章其他位置接受的短术语：只按精确实体 span 决定组件目标。
- 格式计划消费完整未知实体后：旧 `__UMA_KEEP_n__` 缺失检查不得再次要求含 `の` 的原串。

## 3. 其他固定格式与负例

- 追切正例：`5ハロン64秒5―11秒7`。
- 追切负例：普通句子中的 `64秒5`、只有一个时间、没有ハロン或没有末段分隔符。
- 访谈正例：段首骑手 + 括号内马名与名次。
- 访谈负例：普通等号、非名次括号、正文中非署名结构。
- 出马表正例：`<马名><全角空格>○○` 且 `○○` 位于行末。
- 出马表负例：解释 `○○` 含义的说明句、行中普通符号。

## 4. 占位符与失败可见性

- 标题格式占位符只在 `title_zh` 验收，正文格式占位符只在 `body_zh` 验收；摘要不能代替对应字段。
- 首次遗漏时用现有 retry hint 重试；第二次仍遗漏抛 `TranslationResponseError`。
- 成功时 `TranslationRun.raw_response.japanese_format_normalizations` 记录 placeholder、rule、field、source、target。
- 种子术语使用独立的 `__UMA_SEED_n__` 字段级占位符；模型即使倾向把“记录”改成“纪录”，最终仍逐字恢复迁移指定目标。
- 初始 prompt 必须逐编号列出 `__UMA_SEED_n__ => 精确中文目标` 及源词，使模型在不透明 token 位置仍能理解句义；长文中同一词多次出现时不得只给词级映射。
- 种子术语恢复边界须消除模型围绕占位符重复补写的完整词或 `公开级 + 级别` 重叠，`__UMA_SEED_n__类型` 输出单个“类型”、`公开级 + 级别` 输出“公开级别”；仅一字相接但语义成立的“拍卖会会场”不得误删。
- 种子术语占位符遗漏时，重试提示列出具体异常编号并要求从头逐段完整重译；最终遗漏、重复或跨标题/正文字段放置时显式失败，元数据记录来源 span 与精确目标。
- 若一次重试修复占位符后又触发完整性门禁，第三次提示必须累计保留占位符约束、缺失位置上下文与原文末段，不得在不同门禁之间来回回归。
- 同一响应中的固定格式与种子术语违规必须一次性汇总；模型新造或混用占位符命名空间时，重试提示必须明确删除原文不存在的占位符并同时补回真实缺失项。
- 模型新造、跨字段或重复输出 `__UMA_KEEP_n__` / `__UMA_TERM_n__` 时同样必须重试，未知编号不得泄漏到正文，也不得碰巧恢复成错误马名或人名。
- 标题与正文按源文实际占位符次数允许同一实体多次出现；推送摘要可以复用标题/正文已有占位符，但任何新造的 KEEP/TERM/FORMAT/SEED 编号都必须重试，禁止进入 QQ 文案。
- KEEP/TERM 在标题与正文中必须逐字段、逐出现次数守恒；非法命名空间、非数字编号、大小写变异或残缺前缀、多余下划线或继续拼成 `字母/数字...__` 的畸形内部 token 在标题、正文、推送摘要中一律重试，但闭合 token 后正常相邻的 `GI`、`3岁` 等正文不受影响。
- `セレクトセール` 内部重叠的 `セール` 不得生成第二个占位符或破坏较长词。
- 与 `__UMA_KEEP_n__`、`__UMA_TERM_n__` 同时存在时互不覆盖，最终无内部 placeholder 残留。

## 5. 术语迁移矩阵

- 空库首次执行创建唯一概念、中文目标与日英 alias。
- 种子函数重复执行两次，`TermEntry/TermAlias` 数量不增加。
- 英文 alias 大小写变化仍命中同一概念。
- `セレクトセール` 与 `セール` 同时出现时最长跨度优先。
- 同来源已有不同中文、同 alias 属于另一概念或不同类型时明确失败；迁移事务不得部分落库。
- 反向函数不删除已进入运营使用的术语。

## 6. 发布与生产验收

- `translate_news --sync --force --article-id` 允许更新目标中文字段，但保持 `manually_edited_fields` 列表。
- 同步重译任务返回 skipped/未完成时，该文章必须记为 failed，不得继续写入“重处理成功”日志。
- 已发布文章保持 ID、`workflow_status`、`published_to_web_at`、发布配额状态和 QQ delivery 数量。
- 11 篇目标文章逐篇运行翻译与发布校验，公开详情为 HTTP `200`。
- 随机抽取近期日文新文章，检查普通片假名、产驹/追切/访谈/出马表格式及未知马名；发现新技术漏项继续修复并回归。
- web/worker/beat 同一镜像，Redis queue、Celery active/reserved 为空，近时段无 error/traceback；历史写入/网络/公开门禁保持关闭。
