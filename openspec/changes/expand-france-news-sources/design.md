## Context

法国地区当前只有 `france_galop_news` 和 `tdn_france` 两个生产批准新闻源。生产审计显示，这两个源可以访问且抓取窗口成功，但近 24 小时新增为 `0`：France Galop 官方新闻页前 20 条基本已入库，TDN France 只是搜索 `France Galop` 关键词，覆盖范围窄且结果偏旧。法国发布量不足不能只靠修复发布门禁解决，需要单独补充新闻源覆盖。

## Goals / Non-Goals

**Goals:**

- 为法国地区增加可持续抓取的新闻源候选，并通过真实探测确认可访问和可解析。
- 新增 adapter 必须复用现有 `SimpleInternationalNewsAdapter` / `NewsSource` / 生产窗口体系。
- 让法国来源的“无新稿、重复旧稿、解析失败、访问受限、入库后被门禁拦住”可区分。
- 新增来源默认可灰度、可停用、可回滚，不影响其他地区。

**Non-Goals:**

- 不在本 change 中修复英文术语误挡；该问题由 `fix-english-term-gate-region-filter` 处理。
- 不触发外部赛马数据库 importer。
- 不承诺一次性接入所有法国媒体；第一版以稳定、低风险、可验收为准。
- 不绕过发布门禁或 QQ 推送限流。

## Decisions

### 1. 先做候选源探测，再进入生产来源清单

实现时新增或扩展探测命令，对候选法国源输出：

- HTTP 状态、最终 URL、content-type、页面长度。
- 列表可解析数量、前若干条标题和 URL。
- 详情页标题、正文长度、发布时间和图片。
- 与生产库已有 URL / source ID 的重复比。
- 反爬、403、验证码、空样本或结构不稳定标记。

只有探测通过的来源才进入 `NewsSource` 默认清单，并且初始 `production_approved` 可保持关闭，等待运营确认。

### 2. 候选源以“法国赛马相关性 + 可抓稳定性”优先

候选范围可以包括法国本地赛马媒体、法国赛事官方相关媒体和国际媒体的法国赛马频道 / 标签页。实现阶段应真实探测当前可访问性，不把历史可访问性当成结论。

如果来源页面需要复杂 JS 或强反爬，第一版应保持停用或只保留 adapter，不进入生产批准。

第一版只有在至少 1 个新增法国来源通过真实探测、语言处理和解析质量检查后，才能标记为可进入生产灰度。如果所有候选源都 deferred，本 change 不能宣称生产 ready，只能输出 no-go 审计结果并回到候选源选择。

### 3. 来源类型和去重必须清楚

法国新增来源应使用独立 `source_site` 或 adapter key；若来自 TDN 等已有国际站点的不同搜索 / tag，应明确 canonical source site 与地区归类规则，避免同一 URL 在法国和美国重复入库。重复 URL 应保留快照和来源发现信息，但不得制造多篇公开文章。

新增来源的 `source_language` 必须被现有翻译和改写链路支持。若接入法语来源，则实现必须补齐 `fr` 语言枚举 / 配置、翻译 prompt 兼容和测试；若暂不补齐，则法语来源只能保持探测或 deferred，不得生产批准。

### 4. 上线后用窗口数据验收，而不是只看抓取命令成功

法国扩源完成后，需要观察至少几个 15 分钟窗口：

- 各法国来源抓取窗口是否成功。
- 新增和重复数量。
- 入库文章状态。
- 发布候选、门禁原因和公开数量。

这能避免“adapter 测试成功，但生产窗口仍然无新稿”的假阳性。

## Risks / Trade-offs

- [Risk] 法国候选媒体反爬或结构不稳定。  
  Mitigation: 先探测，默认不生产批准；访问受限来源保留为 deferred。

- [Risk] 扩源后入库文章仍因术语门禁不发布。  
  Mitigation: 审计必须分开记录入库不足和门禁阻断；不把扩源结果误判为发布修复。

- [Risk] 同一国际站文章被法国和美国重复归类。  
  Mitigation: 使用 canonical source site、URL/source_article_id 去重，并记录发现来源 metadata。

- [Risk] 一次接入太多来源增加 IP 风控。  
  Mitigation: 第一版控制来源数量，沿用 15 分钟窗口、backoff 和生产批准开关；每源抓取列表数量保持保守。

## Migration Plan

1. 增加候选 adapter 和探测测试，先不启用生产批准。
2. 对候选源执行本地或生产只读探测，保存样本和结论。
3. 通过 `sync` 来源清单写入或更新 `NewsSource`，默认可停用或未生产批准。
4. 灰度开启 1-2 个来源，观察最近窗口。
5. 文档记录来源 URL、启用状态、验收结果和停用步骤。

## Open Questions

- 无阻塞问题。第一批法国候选源最终采用哪些，由实现阶段实时探测结果决定；若没有任何候选源达到生产灰度标准，本 change 应以 no-go 结果收敛，而不是上线空来源。
